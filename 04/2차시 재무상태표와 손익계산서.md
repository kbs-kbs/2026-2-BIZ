## 재무상태표

### 1. 의의
- 보고 기간 종료일 현재의 모든 자산, 부채, 자본을 나타내는 정태적 보고서
- 자산·부채·자본으로 구성되어 자본 구조를 알 수 있음
- 차변의 자산은 조달한 자본을 어떻게 활용하고 있는지를, 대변의 부채와 자본은 자본을 어떻게 조달했는지를 보여 줌

### 2. 구성 요소
| 요소 | 내용 |
| --- | --- |
| 자산 | 기업이 소유하고 금전적 가치가 있으며 앞으로 유용하게 사용할 수 있는 재산. 과거 거래·사건의 결과로 기말 현재 지배되고 미래에 경제적 가치를 창출할 것으로 기대되는 자원 |
| 부채 | 미래에 일정한 금액을 갚아야 할 의무. 남에게 갚아야 할 다른 사람의 몫 |
| 자본 | 소유주인 주주들만의 자산. 총자산에서 총부채를 차감한 잔액으로 순자산 |

- **자산 = 부채 + 자본**

### 3. 자산의 분류
| 구분 | 내용 |
| --- | --- |
| 유동자산 | 1년 이내에 현금화되는 자산과, 1년을 넘더라도 정상 영업주기 내에 실현될 매출채권·재고자산. 당좌자산(현금과 시간 경과로 현금화되는 환금성 높은 자산)과 재고자산(판매 목적으로 보유, 거래가 가장 빈번) |
| 투자자산 | 장기적 투자 수익 창출이나 타 기업 지배를 목적으로 보유하는 비유동자산 |
| 유형자산 | 영업활동에 장기간 사용할 목적으로 취득한 구체적 형태의 자산 |
| 무형자산 | 영업활동에 사용하는 물리적 실체가 없는 자산 |
| 기타 비유동자산 | 투자·유형·무형자산으로 분류하기 어려운 비유동자산 |

### 4. 부채의 분류
| 구분 | 내용 |
| --- | --- |
| 유동부채 | 1년 이내에 지급해야 할 빚. 지급 기일이 1년을 넘더라도 정상 영업주기 내에 지급하는 매입채무 등은 유동부채 |
| 비유동부채 | 지급 기일이 1년 이후에 도래하는 장기 채무. 설비 투자처럼 거액이 필요한 경우 자기자본 조달이나 비유동부채로 재원을 마련 |

### 5. 자본의 구성
| 항목 | 내용 |
| --- | --- |
| 자본금 | 발행 주식의 액면가 상당액. 자본금 = 발행주식수 × 1주당 액면 금액 |
| 자본잉여금 | 자본거래로 인한 자본 증가분 중 법정자본금(액면 금액)을 초과하는 잉여금 |
| 자본조정 | 자본거래에 해당하나 최종 납입 자본으로 볼 수 없거나 자본금·자본잉여금으로 분류할 수 없는 항목 |
| 기타포괄손익누계액 | 아직 손익으로 확정할 수 없으나 포괄적 의미의 잠재적 손익 |
| 이익잉여금 | 이익 창출 활동으로 벌어들인 이익 중 사외로 유출되지 않고 사내에 남은 부분. 자본잉여금과 달리 손익거래에서 발생 |

- 자본 항목은 주주가 불입한 불입자본(자본금, 자본잉여금, 자본조정)과 이를 이용해 창출한 손익으로 구분하고, 창출한 손익은 확정적으로 벌어들인 손익(당기순손익)과 잠재적 손익(기타포괄손익누계액)으로 나뉨

## 손익계산서

### 1. 의의와 구성
- 일정 기간 동안 회사가 달성한 경영성과를 나타내는 보고서
- 수익에서 비용을 차감한 것이 손익(이익 또는 손실)이며, 수익이 발생하면 순자산이 증가하고 비용이 발생하면 순자산이 감소

### 2. 수익
- 경영활동에서 발생하는 경제적 효익의 총유입. 자산의 증가 또는 부채의 감소로 나타남
- 협의의 수익(revenue)은 주된 영업활동과 관련해 발생하며 업종에 따라 표현이 다름
- 광의의 수익인 이득(gain)은 영업 외 활동에서 부수적으로, 일시적이거나 우연적인 거래에서 발생한 순자산 증가분

| 구분 | 내용 |
| --- | --- |
| 매출액 | 상품·제품의 판매나 용역 제공으로 실현된 금액. 회사의 주된 수입원이며 업종에 따라 달라짐 |
| 영업외수익 | 영업활동 외의 보조적·부수적 활동에서 순환적으로 발생. 이자수익, 배당금수익, 임대료, 채무면제이익, 잡이익 등 |

### 3. 비용
- 제품의 판매·생산, 용역 제공, 영업활동을 구성하는 활동에서 일정 기간 발생한 자산의 유출 또는 부채의 발생액
- 협의의 비용은 주된 영업활동과 관련해 발생하고, 손실(losses)은 일시적·우연적 거래에서 발생

| 구분 | 내용 |
| --- | --- |
| 매출원가 | 매출액과 직접 대응되는 원가. 일정 기간 판매된 상품·제품에 배분된 원가 |
| 판매비와 관리비 | 판매 활동이나 회사의 관리·유지에서 발생하는 비용으로, 매출원가에 속하지 않는 모든 영업비용 |
| 영업외비용 | 주된 영업활동 외의 보조적·부수적 활동에서 순환적으로 발생. 이자비용, 대손상각비, 외환차손, 외화환산손실, 기부금, 잡손실 등 |
| 법인세비용 | 회사의 이익에 대해 국가에 납부하는 세금 |

## 재무상태와 경영성과의 관계

### 1. 회계기간
- 기업 실체의 경제적 사상을 측정·보고하기 위해 인위적으로 정한 시간 단위로, 회계기간 또는 회계연도라 함
- 재무제표는 회계기간 단위로 작성하며, 경험적으로 1년을 보편적으로 사용해 왔으나 회계환경의 급변과 함께 짧아지는 경향
- 전기 – 기초(1월 1일) – 기중 – 기말(12월 31일) – 차기로 이어짐

### 2. 두 보고서의 연결
| 구분 | 시점 | 기간 |
| --- | --- | --- |
| 재무상태표 | 특정한 한 시점의 재무상태 | - |
| 손익계산서 | - | 일정 시점과 일정 시점 사이의 경영성과 |

- 일정 기간을 나타내는 손익계산서는 일정 시점을 나타내는 재무상태표에서 출발해 다시 일정 시점을 나타내는 재무상태표와 연결됨
- **이익 = 기말자본 − 기초자본**, 곧 기말자본 = 기초자본 + 이익
- 각 기의 재무상태표는 직전 기의 재무상태표와 그 기의 손익계산서로 이어짐
