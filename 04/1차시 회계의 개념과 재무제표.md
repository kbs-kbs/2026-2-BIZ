## 회계

### 1. 회계의 정의
- 회사의 경영활동에 관심을 갖는 다양한 이해관계자가 합리적인 의사결정을 할 수 있도록 경영활동을 기록·추적해 유용한 재무적 정보를 측정하고 전달하는 과정
- 회사의 경영활동을 기록·요약해 이해관계자에게 전달하는 것이 목적이며, 전달되는 것은 재산 등에 관한 재무적 정보

### 2. 이해관계자와 정보 이용 목적
| 이해관계자 | 알고 싶은 것 |
| --- | --- |
| 주주 | 올해 배당금은 얼마인가 |
| 채권자 | 돈을 빌려주어도 되는 회사인가 |
| 경영자 | 올해 회사의 실적은 얼마인가 |
| 종업원 | 올해 성과금은 얼마인가 |
| 거래처 | 이 회사와 거래를 해도 되는가 |
| 과세당국 | 올해 세금은 얼마인가 |

### 3. 재무회계와 관리회계
| 구분 | 재무회계 | 관리회계 |
| --- | --- | --- |
| 목적 | 외부 공표 | 내부 관리 |
| 정보 이용자 | 주주, 채권자, 정부기관, 협력업체, 고객, 소비자단체 | 경영자, 관리자·실무자, 노동조합 |
| 제공 정보 | 재무제표(재무상태표, 손익계산서, 현금흐름표, 자본변동표, 부속 서류) | 가격 결정, 사업부별 손익, 원가 절감, 자가제조·외부구입 결정, 전략 수립·평가, 사업 타당성 분석, 성과 평가 정보 |
| 정보 유형 | 법규와 규정을 따르며 지키지 않으면 제재 | 이용자의 요구에 따라 다양 |
| 정보 속성 | 과거 경영활동의 결과 | 과거·현재·미래의 결과 및 예측 |
| 산정 주기 | 연간·반기·분기·월 단위로 과거 기업가치 증가 여부 판단 | 필요하거나 요구될 때, 현재·미래의 기업가치 제고를 위한 의사결정 |

## 재무제표

### 1. 개념과 기업회계기준
- 정보 이용자가 대부분 회계 전문가가 아니므로 통일된 기준과 일정한 양식으로 재무 정보를 전달하는 수단이 재무제표
- 일정 회계기간 동안의 경영성과와 기간 말의 재무상태 등에 관한 회계 정보를 이해관계자에게 보고하는 보고서
- 기업회계기준(GAAP): 경영활동을 기록·보고하는 공통 기준이자 모든 회사의 공용어
- 우리나라는 한국채택국제회계기준(K-IFRS)과 일반기업회계기준으로 이원화되어 있으며, 상장기업은 K-IFRS를 의무 적용하고 비상장기업은 둘 중 선택 적용

### 2. 재무제표 기본 가정
| 가정 | 내용 |
| --- | --- |
| 발생기준 | 거래의 영향을 현금 수취·지급 시점이 아니라 거래나 사건이 발생한 기간에 인식해 기록·표시 |
| 계속기업 | 예상 가능한 기간 동안 영업을 계속하며 청산하거나 중요하게 축소할 의도나 필요가 없음. 적시에 재정적 의무를 다하고 당분간 청산의 위협 없이 작동 |

### 3. 재무제표의 종류
| 보고서 | 내용 |
| --- | --- |
| 재무상태표 | 일정 시점의 재무상태를 자산, 부채, 자본으로 구별해 나타내는 보고서. 자산 = 부채 + 자본 |
| 손익계산서 | 일정 기간에 실현된 수익에서 비용을 차감해 순이익을 산출. 과거 기간의 경영성과를 집계해 미래 예측의 기초 자료로 사용 |
| 현금흐름표 | 일정 기간의 현금 유입과 유출을 적정하게 표시하고, 기간 말 현재 자금 동원 능력을 평가할 자료를 제공 |
| 자본변동표 | 일정 기간의 자본 변화 내역을 자본 구성 요소별로 보여 주는 보고서 |
| 주석 | 본문의 정보를 이해하는 데 도움이 되는 추가 정보. 중요한 회계 방침, 자산·부채의 대체적 측정치 설명 등 |

- 현금흐름표의 활동 구분
  - 영업활동: 이익에 직접 영향을 미치는 주된 수익 활동과 투자·재무활동 이외의 거래
  - 투자활동: 현금의 대여와 회수, 유가증권·투자자산·유형자산·무형자산의 취득과 처분
  - 재무활동: 현금의 차입·상환, 신주 발행, 배당금 지급 등 부채와 자본 계정에 영향을 미치는 거래

### 4. 부기와 거래
- 부기: 사건의 사실을 요약·정리해 장부에 기입하는 것. 자산·부채·자본의 증감과 수익·비용의 발생 내역을 일정 원칙에 따라 정리하며, 재무상태표와 손익계산서로 요약됨
- 거래: 기업의 재산 상태에 변화를 일으키는 경제적 사건
- 회계상 거래로 인식하는 조건: 회사의 재산 상태에 변화가 있고, 그 금액을 측정할 수 있어야 함

### 5. 회계순환과정
- 거래의 발생에서 재무제표 작성에 이르는 과정
- 거래의 인식 → 분개장(차변·대변) → 총계정원장으로 전기 → 시산표 → 정산표 → 계정의 마감 → 재무제표
- 회계기간 중에는 분개와 전기를 반복하고, 보고기간 말에 장부를 마감하는 결산 작업을 함
