## 계량경영학

### 1. 개념
- 복잡하고 불확실한 환경에서 발생하는 경영 의사결정 문제를 합리적·체계적인 계량적 방법으로 분석·해결하는 학문
- 여러 모델과 기법으로 경영자가 직면한 문제를 더 합리적·체계적으로 해결하도록 돕는 것이 목표
- 특징: 경영 의사결정을 위한 과학적 방법의 사용, 계량적·객관적·수학적 모델의 사용, 분석적 도구·절차·기법의 사용
- 유사 용어: 경영과학, OR(작전연구), 결정과학, 비즈니스 애널리틱스

### 2. 발전 과정
| 시기 | 내용 |
| --- | --- |
| 1930년대 말 | 영국군이 군사 문제 해결을 위해 학제적 팀 접근법을 사용 |
| 2차 대전 | 미국이 영국의 작전연구를 모방해 작전 분석 팀워크를 구성 |
| 1947년 | 댄치히가 선형계획법을 개발 |
| 2차 대전 후 | 대형 컴퓨터 개발로 경영 문제를 해결하는 분야로 자리 잡고 산업계가 OR 기법을 적용 |
| 1950년대 | 비선형계획법, 정수계획법, 동적계획법, PERT/CPM 개발 |
| 1960년대 | 대기행렬이론, 시뮬레이션 모델 개발 |
| 1970년대 이후 | MIS와 결합해 DSS 탄생, 전문가시스템과 인공지능 개발 |

### 3. 문제해결과 의사결정
- 문제해결: 원하는 결과와 실제 결과 사이의 차이를 규명하고 그 차이를 해결할 조치를 취하는 과정
- 의사결정: 문제 정의 → 대안 결정 → 기준 결정 → 대안 평가 → 대안 선정
- 문제해결의 7단계: 문제 규명·정의 → 대안 결정 → 평가 기준 결정 → 대안 평가 → 최선 대안 선정 → 실행 → 결과 평가
- 질적 분석은 경영자의 경험·판단 같은 기예에 의존하고, 계량적 분석은 계량적 자료와 수학적 모델·기법을 사용. 실제 과정은 문제의 구성(정의·대안·기준) → 문제의 분석(질적 분석·수리적 분석) → 요약과 평가 → 의사 결정으로 진행

### 4. 과학적 방법과 모형화
- 과학적 방법은 가설을 세우고 실험을 설계해 검증하는 과정을 포함하며, 얻은 지식은 경험적·귀납적이어서 반증 가능성이 항상 존재
- 과학적 방법과 의사결정 과정의 대응: 문제의 정의 ↔ 관찰, 가설의 설정, 실험의 설계와 실행 ↔ 대안의 결정과 평가, 가설의 채택·기각 ↔ 의사결정
- 모형은 실제 세계의 특정 현상·실체를 단순하게 요약해 표현한 것. 모든 모델은 가정을 수반하며 가정은 복잡성을 줄여 단순화에 도움
- 좋은 모델은 문제 해결의 관점에서 실체의 핵심을 단순하면서 정확하게 나타낸 것

| 모델 | 내용 | 예 |
| --- | --- | --- |
| 형상모델 | 물리적으로 확대·축소한 원형의 복사판 | 장난감, 사진, 생산라인 |
| 상사모델 | 실제 시스템처럼 기능하는 모델 | 다이어그램, 조직표, 청사진, 속도계, 온도계 |
| 수학적 모델 | 실제 문제를 수학적 기호로 방정식·함수 관계로 표현 | 선형계획 모델 |

### 5. 계량 경영 적용 과정
| 단계 | 내용 |
| --- | --- |
| 문제의 정의 | 문제를 옳게 정의하지 못하면 해가 나오지 않거나 부적합한 해를 얻음. 통찰력·상상력·시간이 필요하고, 한 문제의 해가 다른 문제나 일반 상황에 미치는 영향도 분석해야 함 |
| 수학적 모델 설정과 자료 수집 | 모델이 정교해도 자료가 부실하면 좋은 결과가 없음. 모델은 목적함수와 제약조건으로 나타내며, 자료는 사내 보고서·장부·인터뷰·표본조사·직접 측정에서 얻음 |
| 수학적 모델의 해 | 최적해는 모든 제약조건을 만족하며 목적함수 값을 최적화하는 결정변수의 값. 최적화 모델은 최적해를, 시뮬레이션 모델은 이에 근사한 만족해를 구함 |
| 모델의 타당성 검토 | 모델이 모든 제약을 담지 못했거나 일부를 간과·단순화했거나 자료가 부정확할 수 있어 해를 검토. 검증은 모형이 설계대로 만들어졌는지, 타당성은 모형이 제대로 설계되었는지를 확인 |
| 해의 실행 | 작업자의 저항을 교육·홍보·문서화로 관리하고, 해가 계획대로 지켜지는지, 자료가 시간에 따라 변하지 않는지 추적 |

- 만족해를 구하는 이유: 필요한 자료를 모두 모으는 비용과 시간이 너무 크고, 의사결정자가 제한된 합리성을 가져 분석 능력이 부족

## 시스템이론

### 1. 일반시스템이론의 배경
- 1930년대 오스트리아 생물학자 베르탈란피가 여러 학문 분야를 통합할 공통의 사고·연구 틀을 모색하며 도출
- 1950년대에 통합 이론 체계에 대한 관심이 확산되던 중 경제학자 볼딩이 목적과 기본 골격을 작성해 일반시스템이론으로 정립
- 기존 과학이 현상 간 관계를 단순한 인과관계로 가정한 데 반해, 시스템 학자는 하나의 사건이 다른 사건과의 관계성 속에서 설명되어야 한다고 봄
- 전체성(wholeness)을 강조하며 전체를 구성하는 조직의 복잡성을 이해하는 데 관심

### 2. 시스템의 정의와 특성
- 설정된 목적을 달성하기 위해 둘 이상의 부분·요소가 특정한 관계성 아래 함께 일하는 그룹·조직·유기체
- 사상, 이론, 원리 등이 순서화된 집합체

| 특성 | 내용 |
| --- | --- |
| 목적성 | 반드시 분명한 목적을 가짐 |
| 적응성 | 조건·상황의 변화에 시기적절하게 대응하도록 설정 |
| 제어성 | 규정·한계·궤도에서 이탈하는 사태를 사전에 감지해 수정 |
| 종합성 | 다른 관련 시스템과 상호의존 관계에 있고, 부분 시스템도 전체의 필수 기능을 수행 |

### 3. 시스템의 유형
| 분류 기준 | 유형 |
| --- | --- |
| 계층구조 | 상위시스템, 하위시스템, 동료시스템 |
| 외부 환경과의 상호작용 | 폐쇄형 시스템(독립적으로 활동·존재 유지), 개방형 시스템(외부 환경과 빈번히 상호작용) |
| 불확실성 여부 | 확정적 시스템(상호관계를 확실히 예측), 확률적 시스템(확률적으로만 파악) |
| 추상성 여부 | 추상적 시스템(생각·개념의 정돈된 배열), 물리적 시스템(목적을 향해 상호작용하는 요소의 집합) |

### 4. 시스템 관점의 기업
- 경영환경에서 입력물을 받아 가공 처리해 제품·서비스라는 출력물로 전환하고 다시 환경에 제공하는 시스템
- 입력물은 인력·기술·원자재·자본, 출력물은 제품·서비스와 부산물이며, 이익의 사회적 환원 같은 바람직한 산출물과 환경오염 같은 부정적 산출물이 함께 나옴
- 구성 요소: 목표, 하위시스템(생산·재무/회계·연구개발·인사·마케팅), 하위시스템 간 상호작용, 환경과의 상호작용, 통제와 경계

## 상황적합이론

### 1. 기본 개념
- 조직이나 경영을 보다 현실적으로 접근하는 방식
- 기본 가정은 유일한 최선의 조직 방법이 없다는 것("There is no one best way to organize")이며, 주위 상황에 의존한다는 생각에 기초
- 상황적 변수로 구조(구조학파), 기술(기술학파), 환경(환경학파) 등이 있음

### 2. 등장 배경과 핵심 구조
- 고전이론의 합리적·폐쇄적 조직관이 쇠퇴하면서 1960년대 크게 유행
- 조직의 환경·상황에 따라 적합한 조직구조가 달라진다는 명제에서 출발하며, 조직 효과성을 설명하기 위해 조직구조와 상황 변수(환경, 기술, 규모)의 관계를 살핌
- 고전이론과 가장 뚜렷이 구별되는 점은 하나의 보편적으로 합리적인 조직구조를 추구하지 않고 상황적 조건에 따라 적합한 구조가 달라진다고 보는 사고
- 세 가지 기본 개념: 상황(환경·기술·조직의 크기 등 처해 있는 배경), 구조(업무가 조직화되는 활동 형태로 공식화·집권화·조정·의사전달·행정집중), 적합성(상황과 구조 사이의 조화)
- 상황이론도 가장 중요한 논리로 합리성 또는 효율성을 강조
