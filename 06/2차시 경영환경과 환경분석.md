## 경영환경의 개념

### 1. 특성
- 경영이론에서 환경은 기업과 상호작용하며 변화하는 것
- 기업 조직은 개방 시스템으로 주위의 여러 환경 요인과 상호작용하며, 규모·능력·자원에 따라 환경을 적극적으로 변화시키거나 자신에게 적합한 환경을 선택
- 경영환경은 기업의 성장은 물론 생존 여부 같은 경영성과를 결정하는 매우 중요한 영향 요인
- 환경은 계속 변화하므로, 경영자는 환경의 중요성을 인식하고 변화를 사전에 예측해 적극 대응할 통찰력과 판단력을 갖추어야 함
- 경영자의 주요 과업은 조직이 환경 내에서 제대로 기능하도록 준비하는 것이며, 외부 요인을 이해하고 직면한 상황에 자원을 어떻게 적용할지 고민해야 함

## 경영환경의 분류

### 1. 구분 체계
- 통제 가능 정도에 따라 외부환경(시장환경)과 내부환경(조직환경)으로 구분
  - 내부환경: 주주, 종업원, 경영자, 조직 문화 등 기업에 직접 영향을 미치는 통제 가능 영역
  - 외부환경: 통제 범위를 벗어난 일반환경과 어느 정도 통제가 가능한 과업환경으로 구분
- 영향 여부에 따라 직접환경과 간접환경으로 구분
  - 외부환경의 직접환경(과업환경): 소비자, 경쟁자, 지역사회, 금융기관, 정부
  - 외부환경의 간접환경(일반환경): 경제적, 기술적, 정치·법률적, 사회·문화적 환경
  - 내부환경의 직접환경: 주주, 경영자, 종업원, 조직 문화

### 2. 일반환경
- 거시환경이라고도 하며 중장기적이고 간접적으로 영향을 미치는 요인
- 기업이 직면한 기회와 위협에 대한 이해는 일반환경의 이해에서 시작하고, 전략 분석의 외부분석은 일반환경을 고려한 산업 분석을 기초로 함
- 국가 경쟁 상황이나 법·제도와 같은 환경으로 정치, 국민, 경제, 문화 등과 관련
- 각 부분이 단절된 것이 아니라 상호 연결·상호작용하므로 한 부문의 변화가 다른 부문에 연쇄적 영향을 미치고, 시대와 사회에 따라 독특한 특성을 나타냄
- 기업이 통제할 수 없지만 성장의 기회를 제공하기도 하고 제약 조건이 되기도 하며, 소비자의 사고방식·라이프스타일·욕구에 영향을 미침

| 요인 | 내용 |
| --- | --- |
| 정치·법률적 환경 | 법률의 제정·개정과 규제의 완화·강화는 정부의 정치적 성향과 동기가 구체화된 것. 정부 여당의 정책 기조, 정치·정당 체계, 정치 풍토, 안정도가 주요 요인. 세금, 노동법, 무역 제재, 환경법, 관세 등이 위협 요인이 되고, 정부 보조금·특허법·연구개발기금·중소기업 육성 정책이 기회 요인이 됨 |
| 경제적 환경 | 한 경제권 내의 생산과 소비에 영향을 미치는 모든 경제적 요인. 경제성장률(투자 유인), 금리(금융비용과 투자), 환율(수출입 가격 경쟁력), 물가상승률(실질 구매력 감소, 금리 인상 유발)을 주요 요인으로 검토 |
| 사회·문화적 환경 | 사회의 관습과 문화, 가치관, 생활양식, 인구통계학적 변인 등 구성원의 생각과 행위에 영향을 미치는 제도와 태도. 사회가 다원화될수록 변화의 분석·예측이 어려워지고 대응하지 못하면 경쟁에서 탈락 |
| 기술적 환경 | 일반환경 요인 중 변화가 가장 빠르고 심한 요인. 새로운 기술로 제품 진부화와 경쟁 증가가 일어나고, 신제품 개발·보급과 새로운 사업 기회도 늘어남 |

### 3. 과업환경
- 미시환경·운영환경·산업환경이라고도 하며, 단기적이고 직접적으로 영향을 미치는 요인
- 소비자, 경쟁자, 공급자, 금융기관, 지역사회, 정부의 움직임에 영향받음

| 요인 | 내용 |
| --- | --- |
| 소비자 | 재화·서비스의 직접 구매자로서 외부환경 요인 중 가장 강력하고 중요. 일반환경에 따라 구매 행태가 달라지고 소비자 운동의 활성화 정도에 따라 영향력이 달라짐 |
| 경쟁자 | 동일·유사 제품을 제공해 직접 영향을 미침. 기존 경쟁 기업이 많을수록, 시장점유율·규모·영업 방식이 유사할수록 경쟁이 치열. 산업 성장률이 낮거나 진입 장벽이 낮을수록, 대체재가 많고 신규 대체재 출현 가능성이 높을수록 경쟁이 심해짐 |
| 공급자 | 인적·물적 자원을 공급하는 중요한 직접 요인. 공급사슬관리는 수요자가 공급자를 선정해 지속적으로 기술적·경제적 지원을 하며 우수한 재료·부품을 공급받는 관리 체계 |
| 금융기관 | 타인자본 대부분이 증권회사(회사채)나 은행(직접 차입)을 통해 조달되므로 자본을 공급하는 공급자 |
| 지역사회·정부 | 지역사회는 다양한 차원에서 경영활동과 밀접. 정부는 정치·법률적 환경과 밀접하며, 정치 환경은 특정 산업·기업에, 법률 환경은 모든 산업·기업에 일률적으로 영향 |

### 4. 내부환경
| 요인 | 내용 |
| --- | --- |
| 주주 | 소유와 경영이 분리된 주식회사에서 경영을 위탁받은 전문경영자의 활동이 주주 부의 극대화를 위해 이루어지도록 유도·감시. 외국인 대주주의 증가로 주주 부 극대화와 글로벌 스탠더드 요구가 강해짐 |
| 종업원 | 자본과 함께 중요한 생산 요소. 경영자는 노동조합을 적대 관계가 아닌 동반자 관계로 인식해야 함 |
| 경영자 | 경영활동의 방향을 결정하고 지휘하며 목표 설정과 달성의 중심에 위치. 전문경영인 체제의 도입으로 역할과 영향력이 더욱 커짐 |
| 조직문화 | 구성원이 공유하는 가치관·신념·사고방식. 과업 수행과 행동을 지배하고, 바람직한 조직문화는 구성원의 몰입을 높여 목표 달성에 기여하는 기업 자산 |

- 대리인 문제: 정보의 비대칭성 때문에 양질의 대리인이 시장에서 축출되는 역선택과, 대리인의 태만으로 인한 도덕적 위해가 발생해 경제적 피해를 입을 수 있는 상황

## 환경분석

### 1. 외부환경의 두 차원
| 차원 | 내용 |
| --- | --- |
| 변화의 정도 | 환경이 안정적인지 동태적인지를 나타내는 정도 |
| 복잡성의 정도 | 상호작용해야 할 환경 요인의 수와 다양성, 정교한 지식의 필요성. 소비자·공급자·경쟁자가 많고 제품·소비자에 정교한 지식이 필요할수록 복잡성이 높음 |

- 두 차원의 조합으로 불확실성의 수준이 결정되며, 경영자는 이를 통해 기회·위협·제약 요인을 파악

### 2. 외부환경 분석 도구
| 도구 | 내용 |
| --- | --- |
| PEST 분석 | 정치·경제·사회문화·기술 환경의 앞글자를 딴 거시환경 분석. 산업을 둘러싼 거시환경 영향 요인을 추출해 현재와 미래의 기회·위협을 분석. 법적 환경을 더해 SLEPT, 환경을 더해 PESTEL로 부르기도 함 |
| STEEP 분석 | 사회·기술·경제·생태환경·정치 영역으로 거시적 동향을 탐색. 다른 도구와 달리 자연환경·생태환경이 포함되어 날씨, 환경오염, 자외선 증가, 온도 상승 등을 분석 |

### 3. 내부환경 분석과 전략적 대응
- 내부환경 분석은 외부 기회를 이용해 목표를 달성할 능력과 역량이 있는지 판단하는 것
- 경영자는 내부 분석에서 파악한 강점·약점에 자신의 가치 시스템을 결합해 기업이 무엇을 할 수 있는지 결정
- 외부환경 분석(기회·위협·제약)과 내부환경 분석(강점·약점)을 대응시켜 활동 영역인 제품·시장을 결정하는 전략적 의사결정을 수립
- 경영전략: 기업 조직의 목표 달성을 위한 경영활동의 방향과 내용을 결정하는 포괄적·통합적 틀

| 대응 방식 | 내용 |
| --- | --- |
| 환경 적응 | 경계 역할의 증대(외부 핵심 요인과 조직을 연결·조정하고 자료를 수집·분석), 계획부서의 강화(추세 분석과 계량적 경제모형으로 예측), 조직구조의 변경(환경 불확실성이 크면 정보 흐름이 자유롭고 규칙이 최소화된 유기적 조직구조가 효과적) |
| 환경에 대한 영향·통제 | 광고·홍보로 수요 창출과 이미지 제고, 정치적 활동으로 입법·규제 완화에 영향, 동업자협회 결성, 경쟁사·공급업체·유통업체와의 합병이나 조인트벤처를 통한 공동 운영 |

- 내부환경 요인은 통제할 수 있어 능동적으로 대응할 수 있지만, 대부분의 외부환경 요인은 통제할 수 없어 수동적으로 적응
- 불확실성은 환경을 이해하고 변화를 예측할 정보가 충분하지 못한 상황이며, 요인의 수와 변화 정도에 따라 달라짐
