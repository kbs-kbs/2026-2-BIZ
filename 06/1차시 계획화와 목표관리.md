## 계획화의 개념

### 1. 정의
- 경영활동을 합리적으로 수행하려면 먼저 기업이 나아갈 방향과 행동 과정을 결정해야 하며, 미래의 여러 대체적 행동 과정 중 기업 목표에 가장 부합하는 것을 선택하는 것이 계획 수립
- 계획화는 목표 달성을 위한 방법을 모색·설정하는 과정으로, 계획은 선택된 행동 대안
- 내외부 환경 분석 → 목표 설정 → 목표 달성을 위한 전략 수립 → 세부 계획 작성으로 이어지는 하나의 과정
- 경영계획: 미래에 대한 예측으로 목표를 설정하고, 그 목표를 효과적으로 달성하기 위해 여러 대안 중 최적안을 선택·결정하는 경영자의 활동

### 2. 계획 수립의 요건과 이점
- 요건: 새로운 기회의 발견, 다양한 위험과 불확실성의 이해, 미래 위협의 회피와 문제 예측, 전략·전술 같은 효과적 행동 과정의 개발
- 이점
  - 조직과 구성원의 집중도와 유연성을 향상
  - 구성원이 조직 목표 달성 방향으로 행동하도록 지침을 제공
  - 조직 전체 목표와 하위 조직·개인 목표의 일관성을 연결
  - 통제 활동이 사전 계획에 근거하므로 성과 측정·평가와 보상·처벌이 합리적으로 이루어짐

### 3. 계획의 조건
- 계획은 의사결정의 기준으로 수립: 모든 경영자가 경영 목표에 주의와 관심을 집중하고, 의사결정은 계획 수립의 근거가 된 목표나 기대 성과를 기준으로 해야 함
- 계획은 유연성 확보가 필요: 내외부 환경이 항상 변하므로 완벽한 계획보다 적절히 대응할 수 있는 유동적인 계획이 필요
- 계획은 통제를 전제로 수립: 계획을 구성원에게 공개해 공감대를 형성하고, 수립 과정에 구성원을 참여시켜 계획과 통제를 연결
- 계획은 비생산적·비경제적 노력을 배제해 경제성과 유효성을 높임

### 4. 쿤츠의 계획 원칙
| 원칙 | 내용 |
| --- | --- |
| 목적과 목표에 대한 공헌 원칙(합목적성 원칙) | 계획의 근본 목적이 기업 목표와 일치해 구성원의 의식적 협동을 유인하고, 수행자에게 적합하고 이해하기 쉬운 내용으로 공헌 의식을 조장 |
| 계획우선의 원칙 | 경영계획은 경영활동보다 우선하는 상위 개념으로 관리기능 수행의 근본 목표. 관리 행동의 지표이자 통제의 기준이 되며, 계획 없는 관리활동은 통제가 불가능 |
| 계획파급의 원칙(계획의 일반성 원칙) | 계획은 특정 계층의 독특한 기능이 아니라 모든 경영계층이 유기적·협동적으로 수행하는 기본적 기능. 설정 단계에서는 기밀을 보장하되 시행 단계에서는 전 계층에 파급 |
| 계획효율성의 원칙 | 주어진 예산과 환경 범위 내에서 최적의 효율성과 경제성을 갖추어야 하고, 다른 대안보다 효율성이 충분히 안정되어야 하며 수행 과정에서도 경제성이 입증되어야 함 |

### 5. 계획의 분류
| 기준 | 유형 | 내용 |
| --- | --- | --- |
| 위계 수준 | 전략적 계획 | 전사적 차원에서 최고경영자가 장기적 방향을 설정하는 포괄적 계획으로, 모든 하위 계획·정책·절차의 모체 |
| | 전술적 계획 | 사업부 차원의 세부 계획. 중간관리자가 내부 환경에 의존해 중기적으로 결정하고 사업부의 활동 범위와 하위 목표를 설정 |
| | 운영 계획 | 전술적 계획을 실천하기 위한 각 단위 부서의 실행 계획 |
| 시간 | 장기·중기·단기 | 장기(5년 이상, 전사적·전략적), 중기(2~5년, 사업부 단위의 전술적 계획), 단기(1년 이내, 운영 계획) |
| 내용 | 전략·전술 | 전략은 무엇을 할지 방향과 목표를, 전술은 정해진 목표를 어떻게 달성할지 구체적 방법을 설정 |
| | 정책 | 전략보다 영향 범위가 좁은 상용적 지침으로, 특정 상황에서 의사결정과 행동의 가이드라인 역할을 해 구성원의 행동 범위를 제약 |
| | 절차 | 무엇을 해야 하는지 명시하는 단계적 지시. 정책보다 범위가 좁고 구체적 |
| | 규칙 | 용인될 수 있는 행동의 범주와 해야 할 것·해서는 안 될 것에 대한 구체적 지시 |
| 반복성 | 상용 계획 / 단일 계획 | 상용 계획은 정책·절차·규칙. 단일 계획은 짧은 기간의 구체적 목적을 위한 계획으로 예산안(미래 계획을 화폐 단위로 표현한 1년간의 활동 지침)과 프로젝트·프로그램(정해진 날짜까지 한 번만 하는 일회성 계획) |

- 초점에 따른 구분: 최고경영자는 조직 전체를 초점으로 전사적(전략적)·장기 계획과 전사 차원의 전략·정책, 중간경영자는 사업부를 초점으로 전술적·중기 계획, 하위경영자는 단위·기능 부서를 초점으로 운영·단기 계획과 부서 차원의 정책·절차·규칙

## 계획수립과정과 기법

### 1. 계획 수립 7단계
1. 환경 분석 → 목표 설정
2. 대안의 모색
3. 각 대안의 전제 조건 분석
4. 대안의 평가 및 최적 대안 선택
5. 선택 대안의 실행 계획 수립
6. 실행
7. 평가 및 피드백

- 1~5단계가 실질적 계획 수립에 해당

### 2. 계획 수립 기법
| 기법 | 내용 |
| --- | --- |
| 상황대응계획법 | 환경 변화로 당초 계획이 부적절하다고 판단되면 새로운 환경에 대응하도록 그때그때 대안을 찾아 행동을 수정 |
| 시나리오계획법 | 상황대응계획법보다 장기적인 예측 기법. 전개될 여러 시나리오를 예측하고 각 시나리오에 대응하는 계획을 수립해 환경 변화에 유연하게 대응 |
| 벤치마킹 | 특정 분야에서 우수한 상대를 표적으로 성과 차이를 비교하고, 그들의 뛰어난 운영 프로세스를 배워 자기 혁신을 추구. 분야 선정 → 상대 결정 → 정보 수집 → 성과 차이 확인·분석 → 결과 전파와 공감대 형성 → 혁신 계획 수립 → 실행·평가 순으로 진행 |
| 목표에 의한 관리 | 계획의 영향을 받거나 수행할 구성원이 수립 과정에 참여. 다양한 계층이 참여해 정보와 창의적 아이디어가 늘고, 확정된 계획에 대한 이해도·몰입도와 책임감이 높아져 동기부여와 성과가 향상. 다만 수립에 시간이 많이 소요 |

- 예측은 미래에 어떤 일이 발생할지에 관한 가정을 만드는 과정이며, 모든 계획에는 명시적·암묵적 예측이 포함
- 벤치마킹은 반드시 경쟁사를 대상으로 할 필요가 없고, 운영 기법이나 프로세스가 최고 수준이면 어느 산업이든 채택 가능. 가시적 성과값보다 그것이 나오게 된 근본적 이해와 분석이 필요

| 벤치마킹 형태 | 대상 | 비고 |
| --- | --- | --- |
| 내부 벤치마킹 | 자사 내 타 부서 | 비슷한 기능을 수행하는 부서를 비교 기준으로 삼아 자료 수집이 용이. 다국적기업에 적합 |
| 경쟁사 벤치마킹 | 경쟁사 | 유사 업무를 기준으로 비교하나 정보 수집이 어렵고 정보 공유에 대한 이해가 필요 |
| 기능 벤치마킹 | 타 업종 기업 | 업종과 관계없이 해당 부문의 최우수 기업을 대상으로 하며, 타 업종 운영 방식의 적용 가능성을 조사해야 함 |
| 일반적 벤치마킹 | 모든 대상 | 기능 벤치마킹의 일종. 수주·발주·고객 서비스 등 기본 운영 방식에 대한 벤치마킹으로 가장 근본적 형태이며 최고 중의 최고를 발견하기 가장 용이 |

## 목표관리

### 1. 조직목표와 목표의 역할
- 조직목표가 현실성 있게 설정·실행되면 성과의 유효성과 지속적 성장으로 이어지지만, 그렇지 않으면 업적 수준 저하는 물론 조직의 생존을 위협
- 목표는 조직이 실현하고자 하는 바람직한 상태나 달성하고자 하는 최종 성과
- 조직의 방향, 노력의 초점, 지속성을 제공
- 역할: 조직의 방향(계획 수립과 조직화에 영향, 개인·집단의 노력 방향에 지침), 동기부여, 통제 기반(목표를 기준으로 노력 결과를 평가하고 방향을 수정)
- 기업의 목표는 계획 → 조직 → 지휘 → 조정 → 통제의 관리과정 전체에 작용

### 2. 목표의 요구사항
| 요구사항 | 내용 |
| --- | --- |
| 측정 가능성 | 계량적으로 표시되어야 목표의식이 명확해지고 진보 정도를 평가하기 쉬움. 다만 계량화를 지나치게 강조하면 계량화할 수 없는 것을 소홀히 할 수 있음 |
| 계층성 | 각 계층의 목표가 구조화된 수단–목표 사슬. 한 계층의 목표가 다음 계층 목표 달성의 수단이 되며 질서정연한 상호 보완 관계를 유지해야 함 |
| 네트워크 특성 | 목표가 수평적으로도 연결되어야 함. 수평적 연결이나 상호 지원이 없으면 각 부서가 자기 목표만 추구해 조직 전체 목표 달성에 해를 끼침 |
| 그 밖에 | 분명하고 구체적이어야 하며, 달성 시기와 상당한 정도의 난이도를 포함하고, 어렵더라도 달성 가능해야 함 |

### 3. 목표에 의한 관리(MBO)
- 구성원이 자신의 목표 설정에 직접 참여하고, 평가 방법을 미리 알며, 합의로 설정된 목표의 달성 정도를 상급자와 함께 평가하는 기법
- 목표의 설정과 성과의 평가, 곧 관리과정의 두 축인 계획과 통제를 합리적으로 수행
- 부하와 상급자의 의사소통을 증진해 사기를 높이고 개인의 성과를 조직 목표와 연결

| 장점 | 제한 요인 |
| --- | --- |
| 구성원 개개인에게 기대되는 목표를 제시 | 최고경영자의 지원 부족 |
| 경영자의 목표 수립과 세부 업무계획 설계에 도움 | 목표관리에 관한 설명과 교육훈련 부족 |
| 경영자와 하부 구성원 간 커뮤니케이션 개선 | 권위적인 관리자의 상명하달식 목표 설정 가능성 |
| 조직 목표와 자신의 역할에 대한 인식을 제공 | 목표의 제한 또는 과다, 부서 간 상충된 목표로 인한 마찰, 평가의 지나친 강요, 과중한 서류 작업 |
