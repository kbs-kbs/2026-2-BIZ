## 시장세분화와 표적화

### 1. 시장세분화
- 모든 소비자를 만족시키는 제품·서비스를 제공하는 것은 사실상 불가능하므로, 전체 시장 대신 가장 성공적으로 공략할 수 있는 세분 시장을 선택
- 시장세분화: 집단 내에서는 욕구와 구매행동이 유사하고 집단 간에는 상이하도록 소비자를 몇 개의 집단으로 군집화하는 과정
- STP 전략은 이러한 시장 여건 변화에 따라 도입된 개념

| 도입 단계 | 내용 |
| --- | --- |
| 대량 마케팅 | 규모의 경제와 경험 곡선 활용 |
| 제품 다양화 마케팅 | 형태·질·크기 등에서 차이를 보이는 두 가지 이상의 제품을 생산·제공 |
| 표적 시장 마케팅 | 하나 또는 복수의 세분 시장을 선택해 각 세분 시장에 적합한 제품과 마케팅 믹스를 개발·제공 |

- 세분화 기준: 시장 구조를 가장 잘 나타내는 변수를 채택

| 변수 | 예 |
| --- | --- |
| 지리적 변수 | 지방, 국가·도시 크기, 인구 밀도, 기후 |
| 인구통계적 변수 | 성별, 연령, 소득, 직업, 교육 수준 |
| 심리도식적 변수 | 성격, 라이프스타일 |
| 행동적 변수 | 추구하는 편익, 사용량, 상표 충성도 |

### 2. 표적화
- 세분화와 평가를 거쳐 어떤 시장을 표적 시장으로 선택하고 몇 개의 세분 시장을 공략할지 결정
- 세분 시장의 평가 기준
  - 규모와 성장률: 현재 판매량, 예상 성장률, 예상 수익률을 수집·분석. 소규모 기업은 큰 시장을 감당할 기술·자원이 부족하고 경쟁이 치열하므로 성장 잠재력이 있는 작은 시장을 택하기도 함
  - 세분 시장의 구조: 경쟁 강도, 대체 상품의 위협, 구매자의 힘, 공급자의 힘 등 수익성에 영향을 주는 구조적 요인을 분석
  - 기업의 목표와 자원: 목표에 부합하고 그 시장에서 성공할 기술·자원이 있어 경쟁 우위를 얻고 비용보다 수익이 많다고 판단될 때 진입

| 전략 | 내용 | 유의점 |
| --- | --- | --- |
| 무차별적 마케팅 | 세분 시장 간 차이를 무시하고 하나의 제품으로 전체 시장을 공략. 소비자의 차이보다 공통점에 중점을 두고 대량 유통·대량 광고를 채택 | - |
| 차별적 마케팅 | 여러 표적 시장을 선정하고 각각에 적합한 마케팅 전략을 개발. 제품과 믹스의 다양성으로 각 세분 시장에서 높은 판매고와 강력한 위치를 구축 | 전략 구사 비용이 많이 들므로 증가된 비용을 고려한 예상 수익을 먼저 따져야 함 |
| 집중 마케팅 | 자원이 제한된 경우 큰 시장의 작은 점유율보다 하나 또는 소수의 작은 시장에서 높은 점유율을 추구 | 특정 시장 소비자의 특성을 잘 알아 강력한 위치를 얻으나, 구매 행동이 바뀌면 시장 매력도가 사라짐 |

## 포지셔닝

### 1. 의의
- 소비자의 인식 속에 자사 제품이 경쟁 제품 대비 차지하고 있는 상대적 위치
- 소비자는 구매 결정마다 제품을 재평가할 수 없으므로 결정을 단순화하기 위해 제품·서비스·제조 회사를 마음속 특정 위치에 저장
- 기업은 선택한 표적 시장의 소비자 마음속에 경쟁사 대비 최대의 경쟁 우위를 확보하고자 포지셔닝 전략을 기획하고 마케팅 믹스를 개발
- 포지셔닝은 소비자의 인식 속에 자사의 포지션을 기억시키는 과정

### 2. 포지셔닝 전략
- 소비자의 욕구, 자사 제품·브랜드의 강점과 약점, 경쟁 제품·브랜드의 강점과 약점을 종합해 포지셔닝 위치, 곧 경쟁 우위의 원천을 정함

| 방법 | 예 |
| --- | --- |
| 특정 제품 속성 | 맥도날드의 저가 포지셔닝 |
| 소비자가 추구하는 편익 | 후라보노 |
| 사용 상황 | 게토레이 |
| 특정 사용자 집단 | 존슨앤드존슨의 베이비 샴푸 |

## 마케팅믹스

### 1. 수립
- 기업이 목표 시장에서 마케팅 목표를 달성하는 데 사용할 수 있는 마케팅 도구의 집합으로, 자사가 통제 가능한 전략적 도구
- 시장 특성을 고려해 제품, 가격, 유통, 촉진의 네 요소를 적정하게 혼합하는 것이 4P
- 매카시는 마케팅 관리자가 활동을 수행하기 위해 사용하는 도구로 제시

| 요소 | 내용 |
| --- | --- |
| 제품 정책 | 상표권처럼 소비자가 제품으로부터 향유하는 모든 측면 |
| 가격 정책 | 소비자가 제품 구매로 부담하는 비용과 도매상·소매상에게 부과하는 가격. 중저가 제품 선호 등 |
| 유통 정책 | 도매상·소매상 등 회사와 최종 소비자를 연결하는 중간 매개체에 대한 정책 |
| 촉진 정책 | 기업이 관련된 사람들과 이야기하는 수단(광고) |

### 2. 제품 관리
- 다차원적 제품 개념: 핵심 제품 → 유형 제품 → 확장 제품
  - 핵심 제품: 소비자가 구매하려는 제품에서 기대하는 핵심 혜택. 배고픔을 해결하려 음식을, 목적지에 도달하려 기차표를 사는 경우
  - 유형 제품: 핵심 제품을 구체화한 것. 편리한 운송 수단이라는 기차가 새마을호·무궁화호·통일호 등 서로 다른 특성의 유형 제품으로 구체화됨
  - 확장 제품: 배달, 보증, A/S 등 유형적 속성 외의 부가 서비스가 포함된 제품
- 소비자는 제품을 소비하는 것이 아니라 제품이 주는 혜택을 소비
- 유형 제품의 관리 요소: 제품의 질(기능을 발휘하는 능력), 제품 특성(타 제품과 구별되는 기본 기능으로 지각된 가치와 생산 원가에 의해 결정), 스타일(제품의 외양을 서술)과 디자인(외관과 성능을 모두 포함하는 더 넓은 개념), 포장, 브랜드명
- 확장 제품의 관리 요소: 보장(문제 발생 시 제조업자가 제공할 서비스와 기대 기능을 기술한 공식 보증서), 보증(성능이 기대에 못 미칠 때 환불·교환을 약속하는 보험과 같은 것), 대금 결제 방식, 배달, A/S, 설치

### 3. 가격 관리
| 목표 | 내용 |
| --- | --- |
| 매출 중심적 | 매출 증대와 점유율 확대를 위해 단위당 마진을 낮추고 판매량을 늘려 총이윤을 증대. 일반적으로 시장 침투 가격을 채택 |
| 이윤 중심적 | 이윤 목표를 달성하도록 가격을 책정. 품질·독특함·사회적 지위를 중시하는 소비자를 겨냥해 초기 고가 전략을 추구 |
| 현상 유지적 | 현재의 시장 위치를 유지하려는 기업이 설정. 점유율 유지와 경쟁 제품 가격의 균형 유지를 목표 |
| 기타 | 기업 생존 목표(치열한 경쟁·기호 변화·급격한 시장 축소), 소득 수준에 따라 다른 가격을 책정하는 공공 가격 |

- 가격 결정 방법: 비용 중심(생산·판매 비용에 목표 이익을 더함), 소비자 중심(표적 시장 소비자의 제품 평가와 수요를 바탕), 경쟁자 중심(경쟁사 가격을 가장 중요한 기준으로 봄). 세 방법을 종합하는 통합적 가격 결정이 바람직

| 가격 전략 | 내용 |
| --- | --- |
| 초기 고가 전략 | 신제품 출시 시 혁신 소비자층을 상대로 가격을 높게 책정 |
| 시장 침투 가격 전략 | 일반 대중과 대량 소비층을 흡수하기 위해 낮은 가격을 설정. 규모의 경제가 있거나 단위당 이익이 낮아도 대량 판매로 총이익을 확보할 목적 |

- 할인 유형: 현금 할인(외상·어음 대신 현금 지급 시), 수량 할인(대량 구매), 거래 할인(중간상이 수행한 판매·보관·장부 정리에 대한 기능적 할인), 계절적 할인(계절이 지난 제품 구매)

### 4. 유통 관리
- 유통 경로: 어떤 제품을 최종 소비자가 구입하는 과정에 참여하는 모든 조직체와 개인
- 유통 관리가 필요한 이유는 생산자와 소비자 사이에 시간·장소·형태상의 불일치가 생기기 때문
  - 시간상 불일치: 생산 시점과 소비 시점의 차이. 과일은 가을에 생산해 1년 내내 소비
  - 장소상 불일치: 생산 장소와 소비 장소의 차이. 수산물은 어촌에서 수확해 전국에서 소비
  - 형태상 불일치: 생산 형태와 소비 형태의 차이. 공산품은 대량 생산해 소량으로 소비

### 5. 촉진 관리
- 제품·서비스의 성능에 대해 소비자에게 정보를 제공하거나 설득해 구매를 유도하는 활동
- 촉진 믹스: 광고, 판매 촉진, 인적 판매, PR

| 수단 | 내용 |
| --- | --- |
| 광고 | 신원이 확인된 광고주가 돈을 지불하고 자사 제품·서비스·아이디어를 대중 매체로 널리 알리고 촉진하는 모든 형태의 커뮤니케이션 |
| 홍보 | 제품·서비스·기업을 인쇄·방송 매체의 뉴스나 논설 형태로 다루게 해 수요를 유발 |
| 마케팅 PR | 단순 홍보를 넘어 기업과 사회 사이에 이상적인 관계를 정립하기 위한 여러 활동 |
| 판매 촉진 | 판매를 늘리기 위해 짧은 기간 동안 중간상이나 최종 소비자를 상대로 벌이는 광고·인적 판매·홍보 외의 마케팅 활동 |
| 인적 판매 | 판매원이 목표 고객과 직접 대면해 대화로 제품·서비스 구매를 설득하는 활동 |
