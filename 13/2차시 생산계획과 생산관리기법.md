## 생산시스템 관리

### 1. 생산계획
- 수요예측: 미래의 제품·서비스 수요를 예측해 각종 생산 의사결정의 기초 자료를 제공

| 예측 기법 | 내용 |
| --- | --- |
| 질적 기법 | 개인의 주관과 판단, 다수 의견에 입각 |
| 시계열 분석법 | 과거 수요에 입각해 미래 수요를 예측 |
| 인과형 모형 | 수요와 관련된 변수의 인과관계를 분석해 예측 |

- 설비계획: 생산에 필요한 생산 자재를 준비하는 것. 미래 수요 예측 → 생산능력 추가 요구량 결정 → 생산능력 변경 대안 수립 → 대안 평가 → 설비 의사결정의 절차
- 총괄생산계획(APP): 대상 기간이 6개월에서 2년, 평균 1년인 중기 계획. 수요 충족을 위해 생산설비는 생산능력 범위 안에서 이루어져야 하고 사업 전략 관련 비용이 최소가 되도록 수립. 도표법, 선형계획법, 수송모형, 휴리스틱 기법 등을 활용하며 고용 수준, 재고 수준, 생산능력, 외주 등의 전반적 수준을 결정

### 2. 공정관리
- 생산이 시작되는 시점부터 제품이 생산되기까지의 계획·통제 활동. 양질의 제품을 적시에 생산하도록 인력과 기계설비 등 생산 자원을 합리적으로 활용하는 것이 목적

| 단계 | 내용 |
| --- | --- |
| 절차계획(순서관리) | 작업의 순서, 표준 시간, 각 작업이 행해질 장소를 결정·할당 |
| 일정계획 | 원재료 조달·반입부터 제품 완성까지 모든 작업을 구체적으로 할당하고 수행 시기를 결정 |
| 작업배정 | 작업 순서를 정하고 작업자와 기계에 작업을 배정 |
| 진도관리 | 계획에서 정한 공정·일정·공수에 실제 진행을 합치시키는 활동 |

### 3. 재고관리
- 재고는 많은 자본을 요구하고 납품에 큰 영향을 미치므로 가장 중요한 기능 중 하나
- 목적: 적정 재고로 경제적 손실을 줄이고 초과 재고의 불필요한 비용을 절감, 판매·조업 수준 조정으로 노사 관계를 향상, 고객의 다양한 수요에 유연하게 대처

| 기법 | 내용 |
| --- | --- |
| 고정주문량 모형 | 재고가 일정 수준에 도달하면 미리 정한 주문량을 발주. 주문 간격이 일정하지 않고, 수요가 불확실하고 변동 폭이 큰 재고에 많이 쓰이나 재고 수준을 수시로 조사해야 하는 단점이 있음. 고가격·소품종·재고 파악이 쉬운 제품에 유리 |
| 고정주문기간 모형 | 일정 기간마다 재고를 조사해 부족량을 주문. 주기적으로 조달되는 물품이나 재고 기록을 계속하지 않는 값싼 제품에 사용. 고정주문량 모형보다 많은 안전 재고가 필요해 재고 유지비가 높고, 수요가 일정한 재고에 유용하며 정기 실사가 필요 |
| 절충모형 | 두 모형의 결합. 재고 수준을 정기적으로 검토하되 미리 정한 재주문점 이하일 때만 주문. 주문량 계산이 어렵고 주문량이 변해 안전 재고가 많이 필요 |
| ABC 관리법 | 재고 가치·중요도에 따라 차별 관리. 원가가 높고 수량이 적은 품목이 A, 원가가 낮고 수량이 많은 품목이 C, 중간이 B. A 품목을 중점 관리하며 계속 검토하고 기록의 정확성을 기하는 통제 방식을 사용 |
| 단일기간 재고관리모형 | 식료품 같은 부패성 물품, 유행성 제품, 사용 기간이 제한된 물건의 관리에 사용. 재고 부족비와 재고 과잉비의 합이 최소가 되는 주문량 또는 재고 수준을 결정 |
| 자재소요계획(MRP) | 자재가 원활하고 적절히 공급되게 하는 계획으로, 적절한 시간과 장소에 자재를 공급하기 위해 등장 |

### 4. 품질관리
| 구분 | 내용 |
| --- | --- |
| 통계적 품질관리(SQC) | 통계학적 기법을 적용해 고객을 만족시킬 제품을 가장 경제적으로 생산하도록 생산의 모든 단계에서 품질을 관리. 표본검사법, 관리도법, 도수분포법 등이 있으며 모든 품목을 전부 검사할 필요가 없게 하지만, 품질관리부라는 전문 부서에서만 품질을 통제하는 한계 |
| 종합적 품질관리(TQC) | 어느 한 부서에 국한되지 않고 기업 내 다양한 부문이 품질을 개발·유지·개선하는 활동을 통합하는 시스템. 마케팅·생산·엔지니어링·서비스 부서의 조정으로 소비자 만족을 가장 경제적으로 달성. 품질과 경영관리를 결합해 종합적 품질 보증 체계를 마련 |
| 완전무결점(ZD) 운동 | 종업원 각자가 작업상의 결점을 0으로 해 제품 품질과 신뢰성 향상, 납기 엄수, 원가 절감을 달성하려는 운동 |
| QC 서클 | 10명 이내의 일선 감독자와 종업원이 자발적으로 모여 제품의 질과 문제점을 분석·제안. 품질 향상과 참여적 분위기로 사기와 팀워크를 증진 |

## 생산관리기법

### 1. 적시생산(JIT)
- 일본에서 시작되어 재고가 없는 생산 시스템으로 알려졌고, 도요타 자동차에서 처음 시작
- 재고가 낭비를 일으키는 가장 큰 요인이라고 보고, 한 공정에서 다음 공정으로 작업이 진행될 때 부품의 품질과 전달 시간을 해당 작업자가 책임짐
- 품질팀과 제안 제도를 도입
- 원활한 유통망이 확보되지 않으면 완벽한 생산 시스템이라 할 수 없음(고베 지진, 후쿠시마 지진)
- JIS(Just In Sequence): 현대모비스가 현대자동차의 조립 순서와 동일한 시간대에 모듈을 생산·공급하는 방식으로 도요타 JIT보다 재고 관리가 앞선 형태

### 2. 컴퓨터통합생산(CIM)
- 제조·개발·판매로 연결되는 정보 흐름을 일련의 정보시스템으로 통합한 종합 생산관리 시스템으로, 전체 생산 공정에 컴퓨터를 활용
- 과거에는 제조·개발·판매가 독립 구조였고 이를 지원하는 정보시스템도 독립적이었으나, 종합적 생산관리를 위해 CIM이 개발
- 계획·설계·제조·생산관리 등 부분적으로 자동화된 분야를 통합하고 그 위에 영업·유통·연구 분야 시스템을 구축해 기업 전체의 생산 관련 시스템을 유기적으로 통합
- 소비자 요구에 신속히 대응하고 생산성을 높이며, 실시간 센서 신호에 기반한 폐회로 제어 공정으로 유연한 설계와 생산이 가능

### 3. 제조실행시스템(MES)
- 주문 단계에서 완성 단계까지 모든 생산 활동을 최적화하기 위한 관리 시스템이자 생산공정관리시스템
- 작업 일정, 작업 지시, 품질 관리, 작업 실적 집계 등 제반 활동을 지원
- 생산 계획과 실행의 차이를 줄이기 위해 현장 상태의 실시간 정보를 제공하고 인공지능과 설비 사이의 의사결정을 지원
- 기능: 공정 진행 정보의 모니터링·통제, 설비 제어, 품질 정보 관리, 실적 정보 집계, 창고 운영 관리, 재공품 관리, 자재 투입 관리, 인력 관리

### 4. 자재소요계획(MRP)과 제조자원계획(MRP II)
- MRP: 제품을 구성하는 원자재·반조립품·완제품에 대한 자재 수급 계획과 생산관리를 통합한 최초의 체계적 제조 정보관리 기술
- 목표 생산량을 차질 없이 생산하기 위한 적절한 자재 수급 시기와 수량을 결정하는 도구로, 자재 수급 외에 다른 변수는 없다고 가정하고 계획을 수립
- 제품 구성 정보, 표준 공정도, 기준 생산 계획, 재고 레코드 등의 기준 정보가 필요하며, 어떤 물건이 언제 어디서 필요한지 예측해 비능률적 자원 활용과 낭비를 제거
- MRP II: 자재 수급 외에 생산에 필요한 다른 모든 요소(제약 조건)를 계획에 반영. 직접 요소인 작업자·설비와 간접 요소인 공정 데이터·수주 관리·재무 관리·판매 관리까지 전산으로 관리

### 5. 전사적자원관리(ERP)
- 기업의 부문에 걸친 경영 자원을 하나의 체계로 통합해 시스템을 재구축함으로써 생산성을 극대화하려는 대표적인 리엔지니어링 기법
- 생산·영업·인사·회계·구매 등 각종 경영 자원을 하나로 통합·재구축해 경쟁력을 높임

| 특징 | 내용 |
| --- | --- |
| 통합 시스템 | 수주에서 출하까지 생산·마케팅·재무·인사를 공급망으로 통합 |
| 실시간 정보 처리 | 응용 프로그램을 상호 연결해 실시간으로 정보를 처리 |
| 기업 간 자원 활용 최적화 | EDI, CALS, 인터넷 등으로 기업 간 연결 시스템을 확립 |
| 경영혁신 도구와 연결 | BPR과 연계해 경영혁신 도구로 활용 |
| 개방형 시스템 | 다른 하드웨어 업체의 시스템과 조합하는 멀티 벤더 구성, 복수 생산·재고 거점 관리, 경제적 아웃소싱으로 개발·보수가 가능 |

- 기대 효과: 원가 절감, 품질 향상, 업무 생산성 향상, 고객 인지도 향상

## 공급사슬관리

### 1. 개념
- 공급사슬: 자재와 서비스의 공급자로부터 생산자의 변환 과정을 거쳐 완성된 산출물을 고객에게 인도하기까지의 상호 연결된 사슬. 원재료 공급업체, 제조업체, 유통업체, 최종 소비자를 포함
- 개별 기업의 경쟁력만으로는 전체 경쟁력을 보장하지 못하므로, 공급망이 총체적 접근으로 동일한 목표를 달성하기 위해 상호작용
- 기존 혁신 활동의 한계를 극복하려면 공급망 전체를 보는 시야가 필요

### 2. JIT의 한계와 SCM의 목적
- JIT는 생산성은 높였으나 수익성 향상이 없었고, 제조 부문의 재고는 크게 줄었으나 유통 부문의 재고가 늘어 전체 효율에는 큰 변화가 없었음
- 문제의 배경: 기업 내 일부 부문의 최적화만 이루어지고 개별 기업 안에서만 최적화를 목표로 해, 외부 부문·기업과 연계한 공동 또는 전체의 최적화가 되지 못해 성과가 제한적
- 공급사슬관리: 공급자로부터 기업 내 변환 과정, 유통망을 거쳐 최종 고객에 이르기까지 자재·서비스·정보의 흐름을 전체 시스템 관점에서 관리
- 목적: 자재 흐름을 효과적·효율적으로 관리해 불확실성과 위험을 감소, 재고 수준·리드타임·고객 서비스 수준을 향상, 기업 내 부문별·개별 기업 단위 최적화에서 벗어난 전체 최적화 달성
- 기대 효과: 공급망 내 불확실성과 낭비 요소 제거, 최적 비용으로 요구되는 서비스 수준을 제공해 사업 가치를 극대화, 서비스 수준을 높이고 총비용을 최소화

### 3. 공급사슬의 통합 단계
| 단계 | 내용 |
| --- | --- |
| 1단계 독립적 공급사슬 주체 | 외부 공급자·고객을 기업과 독립적으로 간주하고 내부의 구매·생산통제·배급 기능도 독립 운영. 각 주체가 자기 재고만 통제하고 독자적 시스템을 사용해 조직적·기능적 장벽으로 많은 재고가 존재하며 흐름이 비효율적 |
| 2단계 내부 통합 | 구매·생산통제·배급을 자재관리부서로 결합해 기업이 직접 통제하는 부분을 통합한 내부 공급사슬을 창출. 구매에서 배급까지 통합된 정보·자재 통제 시스템을 사용하나 공급자·고객은 여전히 독립적 실체로 간주 |
| 3단계 공급사슬의 통합 | 내부 공급사슬과 외부 공급자·고객을 연결해 전체적으로 공급사슬을 통합 |
