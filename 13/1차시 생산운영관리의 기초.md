## 생산운영관리의 개념

### 1. 정의
- 생산운영관리: 조직에 속한 모든 물적·인적 자원을 최대로 활용해 장기적 이익을 극대화하려는 인간의 활동
- 생산: 여러 투입 요소의 변화 과정을 거쳐 제품 또는 서비스라는 경제적 부가가치를 창출하는 과정
- 운영: 제품과 서비스의 생산을 다루는 기능 분야
- 서비스: 무형으로, 서비스 프로세스는 고객에게 가치를 제공하는 데 물리적인 것이 아니어서 정의·측정이 어려움
- 생산관리는 제품과 서비스의 생산과 관련된 관리활동으로, 양질의 제품·서비스를 적기에 생산·공급하도록 계획·조직·통제해 생산성을 향상시키는 기능
- 목표는 전환 프로세스의 부가가치, 곧 생산성의 증대

| 지표 | 내용 |
| --- | --- |
| 부가가치 | 산출 금액 − 투입 금액 |
| 생산성 | 산출량(금액) ÷ 투입량(금액) |
| 노동생산성 | 노동자 1인이 일정 기간 투입된 노동량에 따라 산출하는 생산량 또는 부가가치 (부가가치 ÷ 종업원 수) |
| 조업도 | 조업률·가동률이라고도 하며, 보유 생산능력의 최고 한도 또는 최적 조업을 100으로 하여 지수화 (실제 생산량 ÷ 표준 생산량) |

- 생산관리 대신 생산운영관리라는 용어를 쓰는 이유는 그 범위가 제조업뿐 아니라 서비스업까지 적용되기 때문

| 구분 | 내용 |
| --- | --- |
| 협의의 생산운영관리 | 생산의 계획과 통제를 통해 생산 목표를 효율적으로 달성하기 위한 관리. 생산 계획의 입안과 계획에 기반한 진행 과정의 통제, 공정 관리는 계획과 실적 차이 분석으로 문제점과 원인을 분석해 대책을 마련 |
| 광의의 생산운영관리 | 사업 전략과 목표 달성을 위해 투입물, 관리 프로세스, 산출물 전체를 최적화하는 전략 입안과 계획·통제 기능. 성과 실현을 위한 조직·제도·시스템의 정비와 전 수명주기 관리 |

### 2. 생산관리의 발전 과정
| 단계 | 내용 |
| --- | --- |
| 과학적 생산관리 | 테일러의 시간·동작 연구로 과업의 표준량을 정하고 작업량에 따라 임금을 지급해 생산성을 향상. 작업에 대한 과학적·합리적 연구를 강조(테일러·포드 시스템) |
| 인간관계의 생산관리 | 메이요의 호손 실험을 계기로 인간의 존엄성과 비공식 집단의 활동을 고려. 작업 설계에서 동기부여와 인간적 요소의 중요성을 강조 |
| 시스템적 생산관리 | 투입 → 프로세스 → 산출이라는 시스템 이론을 이용. 의사결정 모형과 경영과학, 즉 수학적·계량적 모형의 활용 |

### 3. 현대 생산관리의 원칙(3S)
- 노동의 양보다 강도를 강화하기 위해 대량생산의 기본 원칙으로 전문화, 표준화, 단순화를 요구

| 원칙 | 내용 |
| --- | --- |
| 단순화 | 제품과 부분품의 낭비를 막기 위해 불필요한 제품의 종류·규격·품목을 줄이는 것. 물건의 형상을 간단히 하고 업무 방법을 간단히 하는 행위도 포함 |
| 전문화 | 특정 제품을 전문적으로 생산하고 작업 내용을 분화, 곧 분업으로 생산성 향상을 추구 |
| 표준화 | 제품의 규격·치수·원재료 등 표준을 규격화해 부품을 공용화·범용화하고 대량 생산·유통의 비용을 절감 |

### 4. 생산시스템의 유형
| 구분 | 내용 |
| --- | --- |
| 주문생산(MTO) | 고객의 주문을 받아 생산 |
| 계획생산(MTS) | 수요 예측을 통해 계획 생산 |
| 혼합생산 | MTO + MTS |
| 개별생산 | 1회성 주문 생산 또는 프로젝트성. 수제화, 건축, 교량 |
| 단속생산 | 고객 주문에 의한 주문자 생산 방식. 중장비, 의료기기 |
| 반복생산 | 연속적인 조립 라인 생산. 자동차, 전자제품, 반도체 |
| 연속생산 | 표준화된 제품을 반복 생산. 철강, 석유화학, 설탕 |
| 유연생산시스템 | 생산성을 줄이지 않으면서 유연성이 풍부한 자동화 생산 라인(고도의 수치제어 공작기계, 로봇 개발 등) |

### 5. 생산능력의 유형
| 유형 | 내용 |
| --- | --- |
| 실제 생산능력(설계 능력) | 설계상 이론적으로 산출할 수 있는 최대 생산량 |
| 기대 생산능력 | 설계상 최대한 달성할 수 있는 수준. 제품 변경, 스케줄, 품질, 설계 보전 등 예기치 못한 사항으로 최대치를 달성하지 못함 |
| 실제 생산량 | 기업 활동을 통해 실질적으로 달성하는 생산량. 설비 고장, 결근, 정전 등이 영향 |
| 최대 생산능력 | 정상 조건에서 생산설비를 최대로 이용할 때의 생산능력(정기 점검·유지보수 시간은 제외) |
| 피크 생산능력 | 정상 시간 외 잔업·특근을 포함한 단기적 생산능력 |

## 생산관리의 기본 활동

### 1. 생산관리의 네 가지 목표
| 목표 | 내용 |
| --- | --- |
| 원가 | 생산원가는 재료비·노무비·간접비를 포함하며 매출액 대비 비율이나 단위당 원가로 표시. 원가 최소화를 목표로 하면 신제품을 신속히 도입할 유연성을 희생하고 고도의 자본집약적 대량생산에 집중. 설비는 오래 사용하고 낮은 비용으로 유지하며 완제품·원자재 재고를 최소화 |
| 품질 | 가치·탁월성·규격 일치성·고객이 느끼는 유용성 등. 고품질 설계와 균일한 품질을 함께 추구하고, 고객 만족도·불량률·폐기물 및 재작업 비율로 측정. 품질에 중점을 두면 설계 품질과 적합 품질을 모두 강조 |
| 납품 | 고객이 원하는 시간과 장소에 제품·서비스를 인도하는 능력. 빠른 납기, 정시 납품, 개발 기간 단축으로 측정하며, 재고 생산은 재고로 충족되는 수요 비율이나 재고 보충 시간으로, 주문 생산은 주문 후 인도까지 걸리는 시간과 약속한 납기에 인도된 비율로 측정 |
| 유연성 | 수요의 양적·질적 변화에 신속히 대응하는 능력. 생산 수량을 신속히 조절하고 소비자 요구에 맞춰 신제품을 개발하거나 디자인을 변경하는 능력 |

### 2. 조직 계층별 활동 영역
- 모든 계획과 의사결정은 전략적·전술적·운영적 구분 중 하나에 속함
- 스키너의 40-40-20 법칙: 기업의 진정한 경쟁력과 생산성 향상에 전략계획 수립 40%, 조직의 조정 활동 40%, 내부 운영 효율성 20%가 기여

| 의사결정 | 내용 |
| --- | --- |
| 전략적 의사결정(전략적 접근) | 제품 라인, 마케팅 채널, 새 공장과 유통 센터의 건설 등 선택 |
| 전술적 의사결정(시스템적 접근) | 재무 자원의 배분, 설비 이용, 생산 및 인력 계획 |
| 운영적 의사결정(관리적 접근) | 생산률 결정, 기계 고장과 재고 품질에 대한 조처, 품질 관리 같은 반복 업무 |

### 3. 생산운영관리자의 역할
- 생산담당 이사: 생산부·품질관리부·자재부를 총괄하고 애로 부분 파악, 원가 절감, 가동률 제고 등 세심한 부분까지 관심을 두고 문제를 해결
- 생산운영관리자: 계획 수립, 조직화, 지휘, 통제 활동을 수행

| 기능 | 내용 |
| --- | --- |
| 계획 수립 | 목표 달성을 위한 활동과 지침, 실시 시기를 수립. 산출할 제품·서비스에 대한 계획을 세워 목표 수준·일정·실행 부문의 지침을 정하고 미래 경영활동의 기반을 제공 |
| 조직화 | 계획된 활동에 필요한 인적·물적 자원을 조달하고 누가 실행할지 결정 |
| 지휘 | 변형 과정의 프로세스를 진행하며 임무와 책임을 할당하고 동기를 부여해 계획을 실행. 리더십 발휘와 커뮤니케이션 |
| 통제 | 목표·계획에 대한 성과 측정으로 문제 요소를 개선하고 성과를 평가해 필요한 수정 작업을 함 |

- 계층별 중요도

| 계층 | 계획 | 조직화 | 지휘 | 통제 |
| --- | --- | --- | --- | --- |
| 최고경영층 | 높음 | 중간 | 낮음 | 중간 |
| 중간관리층 | 중간 | 높음 | 중간 | 중간 |
| 감독층 | 낮음 | 낮음 | 높음 | 높음 |

## 생산관리시스템

### 1. 구성 요소
- 생산시스템은 투입, 변환 과정, 산출, 피드백, 경영관리자의 다섯 요소로 구성
- 투입: 원자재, 자본, 설비, 인력, 정보, 에너지. 변환 과정은 가공과 조립, 산출은 완제품과 서비스

### 2. 투입과 산출
- 생산요소 3M(작업자, 기계설비, 원자재), 4M(+방법), 6M(+자연, 측정)
- 투입 자원은 제품 생산에 직접 투여되는 자원(제조업의 원자재, 원유·티타늄 등)과 변환 과정에 필요한 자원(기계설비, 기술자, 에너지, 정보, 주방장·종업원 등)으로 나뉨

| 구분 | 식 |
| --- | --- |
| 효과성(달성률) | 실적 ÷ 계획 |
| 효율성(회수율) | 산출 ÷ 투입 |

### 3. 변환과 창조 과정
- 프로세스: 어떤 일을 처리하는 경로나 공정을 통해 수행되는 모든 작업의 유기적 집합체
- 제조업의 변환 과정은 원자재의 형태가 바뀌는 것으로, 드릴링·연마 같은 가공과 조립이 포함
- 서비스업에서는 변환 과정보다 창조 과정이 존재하며, 소비자 만족을 위해 서비스를 창조

### 4. 경영관리자와 피드백
- 경영관리자는 생산시스템에서 가장 중요한 요소로, 투입물 조달, 변환 과정 통제, 적시적소 산출물 공급, 주문 우선순위 결정, 인원 배정, 동기부여, 원가 통제, 품질 관리를 수행
- 피드백은 생산 과정을 모니터하고 수집한 정보로 다시 생산 과정을 통제하는 활동으로, 성과를 측정해 기준과 비교하고 대비책을 마련해 제품·서비스를 향상시킴
- 피드백은 계층적으로 구분된 조직을 연결하는 도구로, 최고경영층과 중간관리층 사이에는 계획·목표 시달과 성과 보고가 오감

### 5. 생산시스템과 환경
- 생산시스템은 마케팅·재무 등 다른 서브시스템과 서로 영향을 주고받음
- 경제 여건, 정부 규제, 경쟁 상태, 기술 변화 같은 외적 요인이 목표와 정책에 영향을 미쳐 생산시스템에 반영됨
