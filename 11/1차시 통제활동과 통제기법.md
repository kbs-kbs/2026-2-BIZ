## 통제활동의 개념

### 1. 의의
- 관리과정의 마지막 단계로, 피드백을 통해 효율적으로 목표를 달성하는 과정
- 스타이너: 통제의 결과가 계획으로 피드백되어 새로운 계획을 설정해야 한다고 주장
- 쿤츠: 기업의 목표가 달성되도록 계획과 종업원의 성과를 비교·측정해 편차가 있으면 수정하는 활동
- 계획에 따라 목표가 달성되도록 조치를 취하는 과정이며, 목표와 성과 간 차이가 있을 때 이를 최소화해 목표 달성의 효과성을 높이기 위해 시정하는 과정
- 흐름: 목표 설정(측정 방법·기준) → 실적 평가(계획 대 실적) → 목표 ≤ 실적이면 종료(평가 시스템 반영), 아니면 개선 활동 → 피드백

### 2. 필요성
- 경영 관리과정의 기본 과정으로 경영 순환을 마무리하고 다음 계획 수립에 피드백하는 활동
- 계획과 목적은 미래 지향적이고 미래는 불확실성을 품으므로 시간 경과에 따른 통제 포인트가 필요하고, 경영활동과 계획·목표까지도 건설적 조정이 필요
- 규모가 커지고 활동 범위가 다양해지면서 업무 환경의 복잡성이 증가해 체계적·합리적 통제로 여러 활동을 조정·통합해야 함
- 종업원의 실수와 오류를 정정하고 환경 변화에 대한 대응 방안을 제시
- 결과에 대한 책임을 확실히 하고 권한 위양과 분권화를 가능하게 하는 요건이 됨
- 경영환경의 불확실성, 통제의 목적 적합성, 변형된 권한 위양, 성과의 확인, 경영자의 미래 의사결정에 대한 피드백 기능 때문에 필요

### 3. 통제의 기능과 저해 요인
| 기능 | 내용 |
| --- | --- |
| 감시 기능 | 조직의 모든 활동을 감시 |
| 비교 기능 | 실제 성과와 표준 성과의 일치 정도를 비교 |
| 시정 조치 기능 | 실제 성과와 표준 성과의 편차를 시정 |
| 피드백 기능 | 미래 의사결정을 위해 최고경영층에 피드백 |

- 저해 요인: 단기적 생산 목표에 의한 통제, 종업원의 욕구 불만족과 사기 저하를 유발하는 통제, 허위 보고를 조장하는 통제, 지나치게 단편적·부서 중심적인 통제, 통제 자체가 목적이 되는 통제

### 4. 통제와 계획의 연관성
- 계획은 효과적인 경영 상태와 결과를 설정하고, 통제는 상태·결과를 계획과 비교해 차질이 있으면 시정 조치를 지원
- 적시에 정확한 정보가 없으면 효과적인 계획을 세울 수 없고, 통제는 경영자가 필요한 정보를 획득하는 수단

## 통제시스템 구축

### 1. 통제의 기본 방침
- 통제를 위한 통제가 되어서는 안 되고, 직무 목적에 적합해야 하며 경영환경과 직무 특성에 맞아야 함
- 계획의 실행 여부를 반영하고, 계획치와 결과치를 계량적으로 분석해 편차를 구분할 수 있어야 함
- 미래를 예측한 사전적 통제(화재 예방), 목표 지향적 통제, 예상치 못한 상황 변화에 대비한 탄력적 통제, 다수가 여러 번 측정하는 객관적 통제

### 2. 통제시스템의 요건
| 요건 | 내용 |
| --- | --- |
| 확실성 | 확실한 정보로 통제 |
| 적시성 | 의사결정에 영향을 미칠 능력을 잃기 전에 정보를 제공 |
| 경제성 | 통제 소요 비용 < 통제 이익 |
| 유연성 | 새로운 변화에 적응하고 기회를 탐지 |
| 이해가능성 | 통제 자체가 이해 가능한 형태로 제공 |
| 합리적 표준 | 통제의 표준이 합리적이어야 함 |
| 전략적 배치 | 성과에 중요한 영향을 미치는 문제를 먼저 통제 |
| 합리성 | 통제 대상자의 지지를 얻어야 함 |
| 복수 기준 | 여러 기준을 적용해 통제 |

### 3. 통제의 유형
| 분류 | 유형 | 내용 |
| --- | --- | --- |
| 강조점 | 시장 통제 | 경쟁이 심한 상황에서 가격 차이, 시장점유율 등을 통제 수단으로 사용하고 사업 단위별 점유율을 자원 배분·전략 의사결정에 활용 |
| | 관료적 통제 | 규칙·규정·방침·정책을 강조해 구성원이 올바른 행위를 하는지 확인. 직무 설정과 예산을 명시하고 그 범위 안에서만 자율권을 허용 |
| | 공유에 의한 통제 | 최고경영자부터 하부까지 중요한 것이 무엇인지 공유. 구성원의 행위가 공유된 가치·전통·규범·신념에 의해 규정되며, 팀별 성과를 확인 |
| 시간 순서 | 사전통제 | 변환 과정이 시작되기 전 투입 단계에서 시행. 목표의 적절성, 자원의 가용성을 확인하고 예측되는 문제점을 사전 제거(화재 예방 교육). 가장 이상적인 통제 |
| | 실행통제(동시통제) | 실행 중에 표준·목표로부터의 편차를 발견하고 수정 행동을 취함. 수정 비용이 적고 지체 없이 이루어짐 |
| | 사후통제(피드백 통제) | 모든 활동이 종결된 후 실시하며 미래의 유사한 계획 수립에 도움 |

## 통제기법과 분야

### 1. 전통적 통제기법
| 기법 | 내용 |
| --- | --- |
| 예산통제 | 예산(계획을 화폐 가치로 나타낸 것)을 기준으로 실제 업무 성과와의 차이를 분석. 예산 편성 → 집행 → 차이 분석의 단계로 이루어지고, 경영계획의 구체화, 부서 간 균형 있는 계획 전개, 계수적 사고로 경영관리의 과학화, 내부 통제 제도의 기초 마련이 이점. 반면 관리 수단을 넘어서면 복잡성·갈등이 생기고 예산 우선주의에 빠질 위험이 있으며, 유연성·융통성이 낮음 |
| 손익분기분석법 | 생산비·판매량·판매가격이 변할 때 이익의 변화를 분석. 수익과 비용이 일치해 이익이 0이 되는 판매량(매출액), 곧 손익분기점을 분석하며 경영계획·단기 이익계획 수립에 활용. 기업의 이익 구조와 안전도를 알 수 있음 |
| 통계자료이용법 | 각종 통계 자료를 비교·검토·분석하는 가장 쉬운 방법으로 도표를 주로 활용. 경영 현상(추세)을 객관적으로 판단 |
| 판매실적법 | 전기 판매 실적으로 현재와 미래의 판매량을 예측하고 통제 |
| 개인적 관찰법 | 개인의 능력·가능성·개성을 관찰한 자료를 통제 수단으로 이용 |
| 내부감사활용법 | 경영 전반에 대한 정기적·독립적 평가 내용을 통제 수단으로 활용. 회계감사, 업무감사 같은 내부 자문 역할 |

### 2. 현대적 통제기법
- 경영정보시스템: 하위 경영층의 업무를 감독·통제하고, 최고경영층의 의사결정에 필요한 정보를 제공하며 중간경영층의 관리 업무를 지원
- OR 기법: 의사결정 환경의 문제를 수리적 방법으로 해결

### 3. 평가 대상과 분야
- 경영활동의 평가 대상은 투입 요소인 사람·돈·정보와 산출물인 생산(제품·서비스)으로 나뉨

| 분야 | 평가 내용 |
| --- | --- |
| 생산 활동 | 노동생산성(종업원 1인당 부가가치 생산액, 노동자 1인이 일정 기간 산출하는 생산량), 자본생산성(총자본투자효율), 설비투자효율, 부가가치율(부가가치액 ÷ 총매출액), 자본집약도(자본량 ÷ 노동) |
| 재무 활동 | 자금 조달 활동에 대한 평가. 복식부기 원리로 기록하고 경영활동을 과정별로 분류·요약한 정보를 작성해 재무제표 분석, 재무비율 분석, 재무감사(내부·외부 감사)를 수행 |
| 인적자원 | 인적자원관리(HRP 인적자원계획, HRD 인적자원개발, HRU 인적자원활용)로 잠재 능력을 최대한 발휘시키는 관리 활동. 평가 요소는 직무 수행에 관련된 것으로 한정하고, 직무에 맞게 설정하며, 단순·명확해야 하고, 중복되거나 피평가자 간 차이가 없는 요소는 제외하며, 평가 요소와 결과의 일치도가 높아야 함 |
| 정보자원 | 정적 정보관리(대량 정보의 보관·조회·검색)와 동적 정보관리(정보가 조직 내에서 유통·변화하는 과정의 추적)로 구분. 시스템 통제 범위에 따라 일반통제와 응용통제로 나뉨 |

- 외부감사 대상 기업: 직전 사업연도 말 자산 총액 100억 이상인 주식회사, 상장을 앞둔 회사, 직전 사업연도 말 부채 총액 70억 이상이면서 자산 총액 70억 이상, 종업원 300명 이상이면서 자산 총액 70억 이상인 주식회사
- 일반통제: 정보시스템 환경 전반에 영향을 미치는 통제로 관리적 통제(기본 계획, 역할 분담, 인력 선발·훈련·배치, 문서화된 시스템·절차, 예산과 사용자 관리), 시스템 개발 통제, 하드웨어·소프트웨어 통제, 시스템 접근 통제
- 응용통제: 각 애플리케이션에 고유한 통제로 데이터 무결성을 확보. 입력통제(오류·중복 입력·수용 기준 불일치 확인), 처리통제(표본 조사, 결합·요약·분류 같은 프로그램된 절차), 출력통제(정보 무결성 보호와 허가된 사람만의 접근)
