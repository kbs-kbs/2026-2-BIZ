## 경영자의 개념

### 1. 경영자의 중요성
- 경영의 실질적 주체가 경영자이며, 기업 조직의 성패를 좌우
- 경영자의 가치관, 철학, 비전과 목표에 따라 기업의 성패가 결정
- 경영자의 정의와 역할은 경영환경의 변화와 함께 역사적으로 변천해 왔고, 기업 규모의 확대에 따라 소유경영자 → 고용경영자 → 전문경영자로 이어짐

### 2. 소유와 경영의 분리
- 자본가가 담당하는 출자 기능과 경영자가 담당하는 관리 기능이 분화되는 현상
- 자본적 측면: 대규모 자본 조달을 위한 주식회사 형태의 도입으로 부재소유주가 등장
- 경영적 측면: 급격한 환경 변화와 기업의 대규모화로 전문경영인의 필요성이 커짐

### 3. 경영자의 유형
| 유형 | 내용 | 소유와 경영 |
| --- | --- | --- |
| 소유경영자 | 자본의 직접 출연과 운영은 물론 모든 위험을 부담하고 혁신 활동까지 스스로 책임 | 미분리 |
| 기업가 | 기존에 존재하지 않았던 가치와 일자리를 만드는 사람 | - |
| 고용경영자 | 기업가가 경영 기능의 일부를 이양해 일부만 책임지는 유급 경영자 | 형식적 분리 |
| 전문경영자 | 전문 지식과 교육 배경을 갖춘 경영자. 소유와 경영이 분리된 대규모 주식회사에서 나타나며 권한이 경영활동 전반에 미침 | 실질적 분리 |

- 초기 기업과 오늘날 소규모 기업은 출자부터 생산·판매까지 경영의 모든 기능을 소유경영자 한 사람이 수행

## 경영자 계층과 기능

### 1. 구분 기준
- 위계 수준과 직무 범위의 두 기준으로 구분하며, 위계 수준은 직무 내용에 따라 판단되는 상대적 개념
- 위계: 공식 조직 구성원 간 상하 등급을 정해 계층마다 권한과 책임을 배분하고 명령·복종·지휘·감독 체계를 확립하는 것
- 직무: 과업과 작업의 종류·수준이 비슷한 업무의 집합으로, 직책이나 직업상 책임을 갖고 담당하는 일
- 위계와 직무 범위의 대응: 최고경영층은 전반경영자, 중간·하위 경영층은 직능경영자

### 2. 위계 수준별 분류
| 계층 | 내용 | 예 |
| --- | --- | --- |
| 최고경영층 | 환경과 관련해 기업의 장기적 목표·전략·정책을 결정하고 사회적 책임도 짐. 기업 전체에 장기적·전반적으로 영향을 미치는 전략적 의사결정을 주로 수행 | 이사급 이상 |
| 중간경영층 | 최고경영층이 설정한 목표·전략·정책을 집행하는 제반 활동을 수행. 하위 경영자를 지휘·감독하고 때로 노동자에게 직접 명령하며, 최고경영층과 하위경영층의 관계를 조정하는 역할이 가장 중요 | 부장·차장·과장 |
| 하위경영층 | 현장의 노동자·일반 사무원을 직접 지휘·감독하는 운영 또는 일선 감독자 | 직장·조장·반장, 계장·대리급 |

- 지휘(direction): 조직 구성원에게 각자의 일을 시키는 행동(지시)
- 감독(supervision): 계획과 명령이 적절한 방법으로 이행되는지 확인하는 행위

### 3. 직무 범위별 분류
| 구분 | 내용 |
| --- | --- |
| 직능경영자 | 생산·마케팅·인사·재무 등 특정 부문의 활동만 책임지는 부문 경영자. 부문에서는 효율적이지만 기업 전체로는 효과적이지 못한 부문최적화 현상이 생길 수 있고, 부문 간 이해관계가 상충함 |
| 전반경영자 | 기업 전체를 총체적 차원에서 경영하는 총괄경영자. 부문 활동을 조정·통합하며 상대적으로 전략적·거시적 경영활동을 수행 |

- 영업부문은 매출 증대와 시장점유율 확대에, 재무부문은 이익·유동성·낮은 위험·높은 수익성에 관심을 두는 식으로 이해가 갈림
- 오늘날 경영학은 부문 활동의 효율성보다 기업 전체의 목표 달성인 효과성을 중시하므로 전반경영자의 역할이 주요 관심사

## 경영자의 역할

### 1. 민츠버그의 경영자 역할
- 역할: 어떤 직무를 수행하는 데 필요한 행동의 범주. 계층과 무관하게 공식적 권한과 지위에서 비롯되는 공통 역할이 존재
- 민츠버그는 경영자가 공통으로 수행하는 역할을 10가지로 정리하고 3가지로 구분

| 구분 | 역할 | 내용 |
| --- | --- | --- |
| 대인적 역할 | 대표자 | 기업의 외형적 대표로서 행사 참석, 내빈 접견, 고객 접대, 법률 문서 서명 등 상징적 임무 수행 |
| | 리더 | 채용·훈련·동기유발 등 부하에 대한 지휘와 상담. 하위 경영자일수록 중요 |
| | 연락자 | 외부 환경과 조직 내부를 연결하고 공급자·고객 등 이해관계 집단과 관계 유지 |
| 정보적 역할 | 정보탐색자 | 모니터로서 기록물과 접촉을 통해 정보를 꾸준히 수집·분석하고 상부에 보고 |
| | 정보보급자 | 조직 내에서 수집한 중요 정보를 메모·보고·전화·인터넷으로 부하에게 전달 |
| | 대변인 | 수집한 정보의 일부를 조직 내 다른 부서나 기업 외부에 강연·설명·홍보로 공식 전달 |
| 의사결정적 역할 | 기업가 | 성장과 발전을 위해 새로운 사업 기회·아이디어·프로젝트를 제안하고 개발 |
| | 분쟁해결자 | 구성원 간 갈등, 파업, 고객 파산, 계약 위반 등 돌발 사태에 대응해 해결 방안을 제시·수행 |
| | 자원배분자 | 인적·물적·재무·기술·정보 자원을 누구에게 어떻게 배분할지 결정하고 사업 계획의 일정, 예산 집행의 우선순위를 조정 |
| | 협상가 | 조직의 이익을 위해 다른 집단과 협상하고, 노동조합과 단체협약을 맺거나 공급자와 구매·판매 계약을 체결 |

- 정보를 수집·전달하는 것이 경영자 직무에서 가장 중요한 측면

### 2. 카츠의 경영기술
| 기술 | 내용 |
| --- | --- |
| 전문적 기술 | 전문 분야의 고유한 도구·절차·기법을 사용하는 능력. 담당 업무의 메커니즘을 정확히 파악하고 수행할 수 있어야 함 |
| 인간적 기술 | 다른 사람과 같이 일하고, 그들을 이해하며 동기를 부여하는 능력 |
| 개념적 기술 | 모든 이해관계와 활동을 조정·통합하는 정신적 능력. 조직 전체와 부분의 의존 관계를 통찰 |

- 계층별 중요도: 하위 경영층은 전문적 기술, 중간 경영층은 인간적 기술, 최고 경영층은 개념적 기술의 비중이 커짐
