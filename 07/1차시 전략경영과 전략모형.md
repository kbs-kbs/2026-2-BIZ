## 전략경영의 개념

### 1. 전략경영의 정의
- 경쟁적 환경 속에서 조직의 목표 달성을 위해 수행해야 할 활동 영역과 내용, 방향을 결정짓는 선택에 지침이 되는 포괄적·통합적 틀
- 기업이 성과를 극대화하기 위해 전략을 수립·실행·평가하는 모든 과정
- 전략은 전략적 계획 수립의 결과물이며, 목적 수립 → 환경 분석 → 전략 수립 → 전략 평가 → 전략 실천 → 전략 통제의 과정적 접근이 요구됨
- 전략을 세울 때는 인적·물적·조직 자원과 업무 활동의 시스템을 전략에 맞추어 재편성해야 함. 챈들러의 "구조는 전략을 따른다"

| 용어 | 초점 |
| --- | --- |
| 전략경영 | 전략의 수립·실행·평가의 모든 과정 |
| 경영전략 | 목표 달성을 위한 수단으로서 전략의 수립과 실행 |
| 기업전략 | 환경 변화에 기업 전체를 적응시키는 경영전략 |

- 전략경영은 경영전략의 범위를 넘어 평가와 통제까지 포함하는 총체적 활동

### 2. 전략의 정의
| 학자 | 정의 |
| --- | --- |
| 챈들러 | 기업의 장기적 목적과 목표를 결정하고, 목표 달성을 위한 행동을 선택해 경영자원을 배분하는 것 |
| 앤드류스 | 기업의 목표와 목표 달성을 위한 계획·정책. 회사가 어떤 사업 분야에 참여하고 어떤 성격의 회사여야 하는지를 결정 |
| 포터 | 산업 내에서 장기적으로 우수한 재무 성과를 창출하도록 시장 내 위치를 확고히 해 주는 일련의 통합된 선택. 경쟁 우위 확보를 위한 목표 설정과 자원 배분의 계획 및 실행 |

### 3. 전략의 시대적 흐름
| 기간 | 방향 | 주요 주제·관점 | 대표 학자 |
| --- | --- | --- | --- |
| 1950~1970년대 초 | 사업 확장 전략 | 장기 전략 계획. 상품 개발, 시장 확대, 사업 다각화 | 챈들러, 앤소프, 앤드류스 |
| 1970년대 후반~1980년대 중반 | 경쟁 우위 전략 | 산업 구조와 경쟁 분석. 산업 구조 분석, 본원적 전략, 가치사슬 | 포터, 오마에 |
| 1980년대 후반~1990년대 중반 | 핵심역량 전략 | 경쟁 우위 창출·유지. 자원기반관점, 산업 통찰력 | 하멜, 프라할라드 |
| 1990년대 후반~2000년대 | 혁신 전략 | IT 진보의 영향. 파괴적 혁신, 블루오션, 전략적 민첩성 | 아서, 노나카 |

### 4. 전략의 형성
- 민츠버그는 초기 전략을 어떻게 수정해 최종 목표에 도달했는지에 주목
- 의도된 전략: 처음에 세운 전략을 이루기 위해 동기부여하고 실행
- 창발적(우발적) 전략: 예상치 못한 새로운 기회가 올 때 막지 않고 시도한 결과 만들어진 전략
- 창발적 전략이 더 유망하다고 확실해지면 그것이 새로운 의도된 전략이 됨

### 5. 경영전략의 분류
| 수준 | 내용 |
| --- | --- |
| 전사적 전략 | 어떤 시장·산업군에서 경쟁할 것인가. 조직 전체의 장기 방향과 자원 배분 지침, 진출할 사업 영역을 결정 |
| 사업부 전략 | 상대적으로 자율적 운영권을 가진 전략적 사업단위(SBU)가 특정 산업·시장에서 경쟁하기 위한 전략적 의도 |
| 기능부서 전략 | 사업부 전략을 원활히 수행하기 위해 조직의 자원을 어떻게 사용할지에 대한 가이드라인 |

- 기업 수준의 기본전략(그랜드 전략): 성장, 축소, 안정, 결합

| 전략 | 내용 | 유형 |
| --- | --- | --- |
| 성장 전략 | 현재 운영 규모를 확장 | 집중적(내적 성장), 통합적·다각화(외적 성장) |
| 축소 전략 | 규모 축소, 자산 처분·청산으로 비용을 줄여 효율을 높이는 방어적 전략 | 방향 전환, 부분 매각, 해산(청산) |
| 안정 전략 | 기존 규모를 유지하거나 서서히 성장. 기존 시장·고객·점유율 유지 | - |
| 결합 전략 | 두 개 이상의 전략을 동시에 추구 | 특정 사업은 성장, 다른 사업은 축소 |

- 성장 전략의 세부 유형
  - 집중적 성장: 현재 사업 내에서 성장 기회를 모색. 앤소프 매트릭스의 시장침투, 제품개발, 시장개발
  - 통합적 성장: 관련 사업을 구축·획득. 수평적 통합(동일 산업·동일 수준의 기업 흡수), 수직적 통합(자원 공급업체 취득은 후방, 유통업체 취득은 전방)
  - 다각화: 새 제품으로 새 시장에 진출. 집중적 다각화(관련성 있는 제품·서비스), 콩글로머리트 다각화(전혀 관련성 없는 분야)

## 전략계획 수립

### 1. 전략경영 과정
- 외부환경과 내부 상황을 분석해 전략을 수립·실행·평가하고 피드백으로 개선하는 과정
- 내·외부 환경 분석 → 기업 조직의 방향(영역) 설정 → 전략의 수립 → 전략의 실행 → 통제 → 피드백

| 단계 | 내용 |
| --- | --- |
| 환경 분석 | 동종 업계의 경쟁 구조인 산업 환경과 정치·경제·기술·사회 등 거시 환경을 검토해 기회와 위협을 파악 |
| 내부 분석 | 조직구조, 리더십, 기업 문화, 내부 경영 자원을 조사해 강점과 약점을 파악 |
| 전략 수립 | 사명과 비전에 기초해 분석 결과를 이용. 강점으로 기회를 활용하고 위협에 대처하며 약점을 보완하는 전략을 기업·사업·기능 전략의 위계로 수립 |
| 전략 실행 | 계획·예산·절차에 따라 전략을 실제로 수행. 주로 중간·하위 관리자가 담당하지만 조직구조·문화·시스템의 변화가 따르면 최고경영진이 개입 |
| 전략 평가 | 실제 성과와 기대 성과를 비교. 미흡한 점이 발견되면 해당 단계로 돌아가며, 신속한 피드백 시스템이 필요 |

## 전략모형

### 1. SWOT 분석
- 외부 환경의 기회와 위협을 고려하고, 조직의 강점과 약점을 확인·평가해 전략적 대안을 도출
- 좋은 전략은 성장할 기회를 포착하면서 현저한 위협을 완화하는 전략

| 요소 | 내용 |
| --- | --- |
| 강점 | 내부 요소 중 목표 달성에 긍정적으로 공헌하는 요소 |
| 약점 | 내부 요소 중 목표 달성을 방해하는 부정적 요소 |
| 기회 | 외부 요소 중 통제 불가능한 긍정적 요인 |
| 위협 | 외부 요소 중 통제 불가능한 부정적 요인 |

| 전략 | 결합 | 성격 |
| --- | --- | --- |
| SO 전략 | 강점 + 기회 | 성장·확대·강화 (Maxi-Maxi) |
| ST 전략 | 강점 + 위협 | 신기술·신제품·신시장 등 안정 전략 (Maxi-Mini) |
| WO 전략 | 약점 + 기회 | 혁신 운동, 사업구조 재구축, 핵심역량 강화 (Mini-Maxi) |
| WT 전략 | 약점 + 위협 | 방어·축소·철수·다운사이징, 해산·청산 (Mini-Mini) |

### 2. BCG 매트릭스
- 1968년 BCG가 다각화 기업의 사업 포트폴리오 분석·평가를 위해 개발한 도구
- 시장 성장률과 상대적 시장점유율로 사업을 평가하므로 성장–점유 매트릭스라고도 함
- 단순하고 이해하기 쉬워 가장 보편적으로 쓰이지만, 기존 사업 포트폴리오 평가 중심이어서 신규 사업 발굴 도구로는 한계

| 사업 | 성격 | 전략 |
| --- | --- | --- |
| 별 | 성장 제품. 높은 성장률과 높은 점유율 | 유지·구축. 현금은 대체로 균형 |
| 물음표 | 개발 제품. 높은 성장률, 낮은 점유율 | 구축 또는 철수 검토 |
| 현금젖소 | 수익 주종 제품. 낮은 성장률, 높은 점유율 | 유지·수확으로 현금 창출 |
| 개 | 사양 제품. 낮은 성장률과 낮은 점유율 | 철수·수확 |

- 시장 전략은 구축(자원 배분을 늘려 점유율 확대), 유지(현 점유율 유지), 수확(자원 배분을 줄이고 현금 회수), 철수(청산·매각)로 구분
- 물음표 → 별 → 현금젖소로 이동하는 모습이 가장 바람직하나 이동 속도가 너무 빠르면 위험

### 3. 포터의 산업구조분석(5 Forces)
- 1980년 「경쟁전략」에서 산업조직론의 산업구조분석을 기업에 적용하기 쉽도록 변형
- 산업의 경쟁 강도와 수익성, 구조적 매력도는 산업 구조적 특성에 의해 결정되며 다음 다섯 세력이 이를 결정
  - 기존 경쟁사들 사이의 경쟁 정도
  - 잠재적 진입자의 위협
  - 대체재의 위협
  - 공급자의 교섭력
  - 구매자의 교섭력
- 경쟁력 강화 전략을 세우려면 산업 내 구성 집단의 상호 관계를 분석해 경쟁 강도를 파악해야 함

### 4. 본원적 경쟁전략
- 사업부 수준의 전략으로, 시장의 범위와 경쟁 우위의 원천이라는 두 요소를 대응시켜 세 가지 유형을 제시

| 전략 | 내용 |
| --- | --- |
| 차별화 | 독특성을 통한 프리미엄 경쟁. 제품의 고유성을 원천으로 시장 전체를 대상 |
| 원가 우위 | 경쟁업체보다 제품의 원가 구조를 개선해 낮은 비용으로 경쟁. 시장 전체를 대상 |
| 집중화 | 자원이 제한된 기업이 한정된 특수 시장에 집중. 특정 시장에서 차별화를 추구하면 차별화 중심 집중화, 원가를 추구하면 원가 중심 집중화 |
