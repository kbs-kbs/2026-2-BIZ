## 의사결정의 개념

### 1. 정의
- 조직의 전략계획 및 운영계획 목표를 달성할 수 있는 대안 가운데 가장 바람직한 행동 경로를 선택하는 과정
- 개인이나 조직이 주어진 문제를 해결하기 위해 가능한 여러 대안을 모색(탐색)하고 그중 가장 합리적이고 효과적으로 목표를 달성할 수 있는 하나의 방안을 선택·결정하는 과정

### 2. 문제의 계층적 특성
| 문제 유형 | 내용 |
| --- | --- |
| 구조적 문제 | 의사결정에 필요한 일정한 규칙과 절차가 존재하고 문제에 대한 해답이 존재 |
| 반구조적 문제 | 규칙과 절차가 일부분만 존재 |
| 비구조적 문제 | 규칙과 절차가 존재하지 않음 |

- 비구조적·반구조적 문제의 해결에는 의사결정자의 판단이 필요

### 3. 의사결정이론
| 모형 | 제시자 | 전제와 내용 |
| --- | --- | --- |
| 합리모형 | - | 인간을 경제적 인간으로 전제. 합리성과 완전한 정보 환경을 가정하고, 대안을 체계적·포괄적으로 분석해 최적 대안을 선택하는 규범적·이상적 모형 |
| 만족모형 | 사이먼, 마치 | 인간 능력의 한계를 전제. 최적 대안 대신 동의할 만한 차선의 대안을 선택하는 제한된 합리성에 토대. 주관적 합리성 |
| 점증모형 | 린드블롬, 윌다브스키 | 대안은 미래에 대한 성과 예측이므로 처음부터 정확을 기하기 어려움. 시행착오의 환류 정보로 보완하며, 현재 대안과 약간 변형한 제2의 대안을 비교해 향상된 것을 추구하는 기술적·실증적 모형 |
| 최적모형 | 드로어 | 만족·점증모형의 비판에서 도출. 합리적 요소와 함께 직관, 주관적 판단, 창의력 같은 초합리적 요소를 중시 |

- 제한된 합리성: 능력에 한계가 있는 현실적인 인간이 도달할 수 있는 합리성

## 의사결정과정

### 1. 사이먼의 4단계
| 단계 | 내용 |
| --- | --- |
| 탐색 | 조직 내에 나타난 문제나 상황을 인식. 무엇이 문제이고 왜 생기며 어떤 영향을 미치는지 이해하고, 내외부 현황을 지속적으로 모니터링 |
| 설계 | 문제를 해결할 수 있는 가능한 대안을 개발·분석. 원인과 해결 방법에 대한 정보를 수집·분석하며, 주어진 대안을 쓰기도 하고 완전히 새로운 대안을 개발하기도 한다 |
| 선택 | 가능한 대안 중 하나를 선택. 명시적·암묵적 선택 기준을 마련해 각 대안을 평가하며, 창의성·경험·복잡한 정보를 통합하는 능력이 필요 |
| 수행 | 선택한 대안을 실행하고 그 효과를 검토. 목표를 달성했는지, 다른 대안이 더 나은 결과를 가져오지 않았는지 분석 |

## 데이터, 정보, 지식

### 1. 데이터
- 0과 1로 짜인 디지털 데이터, 자료·자재라는 뜻
- 설계·계획에 필요한 자료, 즉 공식, 계산 도표, 치수표, 조사 지표 등
- 정보를 작성하기 위한 기초가 되는 자료이며, 특정 목적에 대해 평가되지 않는 단순한 모든 사항

### 2. 정보
- 가공된 자료. 가공이란 자료를 목적에 맞게 분류·요약하는 것, 사용자에게 의미를 부여하는 과정
- 역할은 의사결정 지원이며, 목적은 개인이나 조직이 직면한 미래의 불확실성 감소
- 사용자에게 실제로 가치가 있거나 가치가 있을 것이라는 확신을 주어야 함

| 좋은 정보의 특성 | 내용 |
| --- | --- |
| 정확성 | 정확할수록 의사결정의 방향과 내용이 올바르게 결정 |
| 시기적절성 | 시기를 놓치면 가치를 상실. 적시란 반드시 현재를 뜻하는 것이 아니라 필요할 때 이용할 수 있음을 의미 |
| 적합성 | 목적에 맞는 정보가 의사결정에 도움을 줌 |
| 증명가능성 | 증명할 수 없으면 신뢰성을 부여할 수 없음. 신뢰성은 원천 자료와 수집 방법에 관련 |
| 그 밖에 | 특수성(특수한 상황에 적합), 유용성(응용 가능한 형태), 명확성, 이해가능성, 검색용이성, 간결성(지나친 정교함은 역효과) |

### 3. 계층별 의사결정과 정보
| 구분 | 주체 | 특성 |
| --- | --- | --- |
| 전략적 의사결정 | 최고경영층 | 절차·정보의 불확실성이 크고 불규칙적. 기업의 성격과 외부 적응에 관한 문제이며, 계량적 기법보다 경영자의 경험과 판단이 우선 |

| 운영적 의사결정 | 하위경영층 | 일상적·반복적 의사결정. 전략적·관리적 의사결정을 구체화하고 실제 활동의 효율을 높이기 위한 결정 |

### 4. 지식
- 정보의 창출·평가·활용에 대한 프레임워크를 제공하는 개념, 경험, 직관
- 원리적·통일적으로 조직되어 객관적 타당성을 요구할 수 있는 판단의 체계로, 영향력 있는 정보

| --- | --- |

| 암묵지 | 언어 등 형식으로 표현될 수 없고 경험과 학습으로 몸에 쌓인 지식 |
