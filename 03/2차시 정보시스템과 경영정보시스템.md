## 정보시스템

### 1. 시스템의 개념
- 공통의 목표나 기능을 달성하기 위해 상호작용하는 요소 또는 실체들로 구성된 집합체
- 시스템의 특성: 뚜렷한 목적, 구성 인자의 상호 유기적 연결, 목적 달성을 위한 자원·정보·에너지의 사용, 그리고 시스템에 입력을 투입하고 출력을 제공하는 환경

### 2. 시스템의 구성 요소
| 요소 | 내용 |
| --- | --- |
| 입력 | 출력을 성립시키기 위한 제어 조건과 데이터로, 자원이 환경으로부터 제공됨 |
| 프로세스 | 입력을 목적에 맞게 출력으로 변환하는 기능 |
| 출력 | 입력 데이터를 조건과 절차에 따라 처리한 결과를 외부 환경으로 전달 |
| 통제 | 목표 달성에 필요한 변환 과정을 올바로 유지하도록 하는 행위 |
| 피드백 | 출력 결과를 감지해 기대한 목표와 다르면 그 차이를 수정 |

### 3. 정보시스템의 개념
- 데이터를 입력받아 정보로 변환시키는 시스템
- 경영관리나 의사결정에 필요한 데이터를 획득·저장·가공하고 그 결과를 제시하거나 검색할 수 있는 시스템
- 조직의 운영·의사결정·통제·관리를 지원하며, 입력–처리–출력의 과정을 가진 시스템

### 4. 정보시스템의 구성 요소
| 요소 | 내용 |
| --- | --- |
| 하드웨어·소프트웨어·데이터베이스·네트워크 | 정보기술(IT)로 묶이는 물리적 구조. 하드웨어는 입력·처리·출력에 쓰이는 모든 물리적 컴퓨터 장치, 소프트웨어는 시스템 소프트웨어와 애플리케이션 소프트웨어, 데이터베이스는 공동 활용·통합 관리를 위한 DBMS·지식관리시스템, 네트워크는 인터넷·인트라넷·엑스트라넷 |
| 프로세스 | 정보시스템을 사용하고 활용하는 조직의 절차·방법·처리 과정. 구매·생산·물류·판매 등 조직의 활동이나 과업 |
| 사람 | 최종 사용자(내부 구성원 + 외부 고객)와 정보시스템 전문가(시스템 분석가, 소프트웨어 개발자, 시스템 운영자) |

## 경영정보시스템

### 1. 개념
- 경영: 기업 경영에서 발생하는 각종 문제를 효과적·효율적으로 해결하는 일체의 의사결정 행위
- 정보: 의사결정에 대한 직간접적 판단 기준이 되는 조직 내외부의 유형·무형 자료를 가공한 것
- 시스템: 공동의 목표(조직 성과의 극대화)를 달성하기 위해 상호작용하는 구성 요소들의 유기적 집합체

| 구분 | 정의 |
| --- | --- |
| 전통적 정의 | 정보를 제공해 의사결정을 지원하는 사람과 기계의 상호작용 시스템 |
| 초경쟁환경에서의 정의 | 정보 콘텐츠를 교환해 의사결정뿐 아니라 혁신과 변신을 돕는 사람과 기계의 상호작용 시스템 |

- 정보시스템과 조직은 서로 영향을 주고받으며, 환경·구조·비즈니스 프로세스·정치와 경영 의사결정·문화·절차 등이 영향 요인이 됨

### 2. 경영정보시스템의 경영성과
- 의사결정의 질 개선: 데이터와 계량 모형으로 의사결정의 효율성과 효과를 개선
- 업무 프로세스 혁신: 제품·서비스 출시 기간을 단축해 시장 선점
- 생산성 향상: 업무 시간을 단축해 능률 향상
- 품질 개선, 고객 만족: 고객 요구와 환경 변화에 신속히 대응
- 비즈니스 프로세스 재구축: 재설계된 업무 프로세스의 구현으로 큰 성과 향상을 기대

### 3. 계층별 정보시스템
- 가장 보편적인 분류 체계는 경영 계층과 연계한 피라미드형 분류
- 운영 업무를 위한 시스템은 기업 활동에서 발생하는 자료를 처리하고, 관리자를 위한 시스템은 관리 활동과 의사결정에 필요한 정보를 제공
- 아래로 갈수록 구조화된 의사결정과 하위 경영층·사무직, 위로 갈수록 비구조화된 의사결정과 고위 경영층에 대응

| 시스템 | 대상·내용 |
| --- | --- |
| 거래처리시스템(TPS) | 1950년대부터 사용된 가장 기초적인 시스템. 기업 운영에 기본적으로 발생하는 거래 자료를 신속·정확하게 처리하고, 일상적·노동집약적 업무의 자동화로 비용을 절감. 양질의 데이터베이스와 접속성이 필요 |
| 정보보고시스템(IRS) | TPS에 저장된 데이터에서 정보를 추출해, 내부 자원과 운영 관리의 효율적 사용에 관심이 있는 관리자를 지원. 일반 작업을 자동화하고 정확한 자료를 실시간 제공해 관리자의 업무 효율을 높임 |
| 의사결정지원시스템(DSS) | 관리자의 의사결정 과정을 지원. 자료를 검색해 문제를 발견하고 해결 대안을 마련하도록 돕는 대화형 시스템으로, 모델과 자료를 활용해 분석·평가를 쉽게 함. 효율성보다 효과성에 비중을 두는 중간경영층을 지원 |
| 중역정보시스템(EIS) | 최고경영자에게 필요한 정보를 제공. 특정 문제에 국한되지 않고 여러 상황에 적용되는 정보를 제공하며, 요약에서 상세까지 제시. 내부는 물론 외부 데이터베이스와의 연결이 필요하고 사용자 편의 위주의 인터페이스가 중요 |

- 정보보고시스템의 보고서 유형: 요약보고서(통계 처리·시간 흐름 정보), 운영보고서(운영 단계의 구체적 정보), 계획보고서(일·주·월 간격으로 생성), 사건보고서(사건·문제 발생 시 생성), 광고보고서(판매 경향과 광고 지출 내역)
