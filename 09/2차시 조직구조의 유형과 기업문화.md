## 조직구조의 개념

### 1. 정의
- 분화된 직능이 유효하게 수행되도록 직능을 분업과 협업의 프레임워크로 형성해 놓은 조직의 형태. 조직 목표 달성을 위해 과업과 구성원을 배치하는 것
- 기업은 생산성 향상을 위해 환경 변화에 맞춰 계속 조직구조를 개선(구조조정)해야 함

### 2. 영향 요인
| 요인 | 내용 |
| --- | --- |
| 환경 | 외부환경에 적합해야 함. 번스와 스토커는 20개 기업을 연구해 생산활동 중심의 기계적 시스템과 환경 변화 적응 중심의 유기적 시스템을 구분. 역동적 환경에서는 유기적 조직이, 안정적 산업에서는 기계적 조직이 능력을 발휘 |
| 전략 | 전략에 후속. 창업 초기 단일 제품에서는 전략이 단순해 구조도 느슨하고 복잡성·공식화가 낮으며, 성장기에는 제품 계열과 활동이 늘어 단위 부서 간 상호 의존성이 커짐. 챈들러는 "조직구조는 전략을 따른다"고 결론 |
| 기술 | 기술의 반복성 정도가 대표적 특성. 기술이 복잡해지면 경영자의 계층과 수가 많아지고 비생산직 비율이 높아짐. 자동차 조립라인처럼 반복적·단순한 기술은 작업 집단 수를 줄여 복잡성을 낮추고, NASA 우주왕복선 개발·연구 활동처럼 비반복적일수록 전문성과 복잡도가 높아져 수직적 분화가 심화 |
| 조직 구성원 | 구성원 간 권력·정략 같은 정치적 변수가 영향을 미침. 정치학적 접근은 조직구조를 내부 구성원의 권력 투쟁의 결과로 보며, 권력을 가진 사람이 자신의 통제권을 행사하기 쉬운 방식으로 구조를 결정한다고 주장 |
| 기업 규모 | 규모가 클수록 직무의 전문화, 절차·규칙·규율의 표준화, 권한의 분산 정도가 커짐 |

## 전통적 조직구조

### 1. 고전적 조직이론의 가정
- 조직을 폐쇄 시스템의 시각에서 논리를 전개하고 외부 환경의 간섭을 배제
- 베버는 관료제를 가장 논리적·효율적인 조직구조로 제시
- 이상적인 관료제의 5가지 원칙
  1. 업무는 명확히 구분되고 각 직위에는 전문가로 충원
  2. 과업 처리 시 따를 일관성 있는 규칙
  3. 명령 체계 형성을 위한 직위의 계층
  4. 경영자는 개인적 감정이 개입되지 않게 하고 부하와 적절한 사회적 거리를 유지
  5. 승진은 기술적 숙련에 기초하고 종업원은 부당한 해고로부터 보호

### 2. 라인과 스태프
| 구분 | 내용 |
| --- | --- |
| 라인 | 경영활동을 직접 집행하는 계층. 1차적 분화로 형성되고 구매·생산·마케팅 같은 기본 기능을 수행하며 명령 하달과 권한 결정의 기능 |
| 스태프 | 라인에 조언과 서비스를 하는 부문. 2·3차적 분화로 형성되고 상황 분석·조사·입안·설명 같은 보조 기능과 조언 권한 |

- 기본 형태: 라인조직, 기능식 조직, 라인과 스태프 조직
- 발전 형태: 사업부제 조직, 매트릭스 조직

## 새로운 조직구조

### 1. 현대적 관점
- 개방 시스템의 관점에서 외부 환경 변화를 수용하고 적응할 능력을 갖추도록 구조를 설계
- 규칙과 통제보다 자유 재량권을 확대하고, 의사결정자의 책임과 의지에 따른 문제 해결이 가능하도록 설계
- 공식적 구조뿐 아니라 비공식적 조직구조도 중요한 고려 대상

| 구분 | 기계적 조직 | 유기적 조직 |
| --- | --- | --- |
| 특징 | 경직되고 안정적인 구조 | 유연한 구조 |
| 초점 | 표준화된 직무와 규정 | 변화에 빠른 대응 |
| 전략 | 비용 통제 전략에 적합 | 차별화 전략에 적합 |
| 환경 | 안정적 환경에서 효과적 | 역동적·불확실성이 높은 환경에서 효과적 |

### 2. 네트워크 조직
- 디지털 경영환경과 인터넷 확산으로 나타난 형태. 조직의 경계가 약해 환경 변화에 유연하게 적응하는 무경계 조직구조로 개방형 시스템의 성격
- 위계적 서열과 관계없이 구성원 개인의 전문적 지식과 자율권에 기초
- 비대해진 조직구조로는 경쟁 환경을 극복하기 어려워져, 아웃소싱·전략적 제휴에 필요한 조직 형태
- 꼭 필요한 최소한의 부서만 운영하고 그 외 기능은 유리한 조건을 얻을 수 있는 다른 조직을 활용해 유연성을 확보

## 기업문화

### 1. 개념
- 문화는 조직의 결정적 변수이며, 조직문화를 이해하려면 사회문화를 이해해야 함
- 문화: 공통된 생활양식, 후천적으로 습득된 사회 구성원의 집단적 심적 프로그래밍, 구성원이 획득한 지식·신념·예술·도덕·관행 및 능력·관습의 복합체
- 조직문화: 한 국가·사회 체계의 문화권 안에 존재하는 하위문화. 조직의 핵심 정체성을 형성하는 가치·신념·행동 패턴
- 구성원의 행동을 지배하는 기본 가정을 강조하며, 기업체의 분위기와 행동 형성의 사회화 과정을 포함
- 가치관, 신념, 이념, 규범, 기술, 의식, 관행, 지식, 전통, 관습, 상징 등이 조직의 태도와 행동에 영향을 미치는 기본 요소

### 2. 샤인의 구성 요소
| 수준 | 내용 |
| --- | --- |
| 인공품과 창조물 | 조직문화를 인식할 수 있는 일차 수준. 표면적으로 나타나 눈으로 볼 수 있는 물질적·상징적·행동적 창조물로, 제품과 기술, 기구, 방침과 규율, 문서, 전통과 일화, 의례, 행동 패턴 등. 전체 인상과 이미지, 표현상의 문화 특성을 형성하는 결정적 요소 |
| 가치관 | 가시적 수준의 인위적 형성을 지배하고 행동 지침을 설정. 구성원이 공유하면 조직의 기본 성격과 특징을 규정 |
| 기본 가정 | 구성원이 너무나 자연스럽게 받아들이는 가정. 기업과 환경의 관계, 현실·시간·공간의 본질, 인간 본성, 인간 활동과 인간관계의 본질 등 묵시적 요소 |

### 3. 조직문화의 기능
- 순기능: 행동 영역을 정의해 다른 조직과의 차이를 창조, 구성원에게 정체성 제공, 개인 이익보다 조직에 대한 몰입 유발, 종업원 언행의 적합한 기준을 제공하는 사회적 접착제로 사회 시스템의 안정 도모, 태도와 행동을 유도·형성하는 감지 및 통제 메커니즘
- 역기능: 기술 혁신과 시장 변화가 가치관 변화와 새로운 행동을 요구하는데, 경직된 문화는 신속한 적응 행동을 저해. 성장 중심에서 균형 유지 중심으로 전환할 때 행동 변화가 어렵고 새로운 가치의 형성·개발이 쉽지 않음
- 문화의 효능은 잠재적이고 완만하게 작용하지만 그 영향은 강대함

### 4. 조직문화와 조직성과
- 구성원이 공유하는 가치와 신념이 행동에 영향을 미쳐 성과로 이어짐
- 세계적 초일류 기업은 우수한 조직문화 특성을 지니며, 강한 문화는 높은 조직성과를 결정하는 중요한 요인으로 재무·경제적 성과에도 영향
- 강한 문화는 구성원에게 강한 정체성을 갖게 해 즐겁게 일하게 하고, 평소 어떻게 행동해야 하는지 명확히 제시하는 비공식적 규율 체계가 됨
