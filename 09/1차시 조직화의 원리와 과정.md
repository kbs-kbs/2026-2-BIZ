## 조직화의 개념

### 1. 정의와 역할
- 계획 과정에서 설정한 기업 목표를 효율적·효과적으로 달성할 수 있도록 과업을 관리 가능한 단위로 세분화하고, 세분화된 과업 활동을 조정하는 시스템을 만드는 작업
- 수행할 업무(직무)의 내용을 편성하고, 직무 수행에 관한 권한과 책임을 명확히 하며, 수평적·수직적으로 권한 관계를 조정해 상호 관계를 설정하는 과정
- 기업 조직에서 수행할 일을 누가 실행할 것인가를 결정하는 과정이며, 경영자에게 요구되는 가장 중요한 역할
- 역할: 목표 달성에 필요한 구체적 활동을 확정 → 관련 있는 활동을 묶어 구조화(부문화·집단화) → 구조화된 활동을 직위에 할당하고 책임·권한 관계를 확정

### 2. 조직화의 중요성
- 업무의 흐름을 명확히 하고 개인별 직무 지침을 제공
- 각 직무를 성공적으로 수행할 행동 체계를 마련해 계획 수립과 통제에 도움
- 의사소통과 의사결정의 경로를 수립
- 직무의 중복과 과업 갈등을 제거
- 구성원의 활동을 조직 목표에 연결해 직무 수행 결과를 증대

### 3. 조직화와 조직
- 조직: 개인이 성취할 수 없는 목표를 성취하기 위해 함께 일하는 사람들의 구조화된 집단. 인간은 효율을 위해 분업을 통한 생산을 하고, 분업을 위해 모인 것이 조직
- 브라운: 구성원이 경영 목표를 성취하도록 직무와 구성원 사이의 관계를 규정하는 것
- 테리: 경영 목표 달성에 필요한 제직능을 마련하고, 이를 집행하는 데 부여된 권한과 책임을 명백히 하는 것
- 샤인: 공동 목적 달성을 위해 노동과 직능을 분화하고 책임과 권한을 부여한 계층을 통해 여러 사람의 활동을 합리적으로 조정하는 것
- 조직은 구조적인 것(organization)과 과정적인 것(organizing)으로 나뉨

### 4. 조직의 속성
| 속성 | 내용 |
| --- | --- |
| 인간 집단 | 복수 구성원 간 이해관계·가치관·스타일의 조정을 통해 바람직한 관계와 상호작용을 도모 |
| 공동의 목표 | 공통 목적을 집단적으로 추구하기 위해 자원과 역량을 동원. 목적 공유는 자동으로 보장되지 않으므로 조직 전체에 걸친 목적 공유가 중요 |
| 체계화된 구조와 절차 | 공식 구조로 분업·협업, 행동 조정, 통제 등 관계의 효율성을 도모 |
| 환경 적응 | 협력 관계의 지속성·영속성을 가정. 일시적 협력은 조직이 아니며, 구성원의 연한을 초월한 존재·목적 활동·구조의 지속성을 가정 |
| 조직의 경계 | 외부 환경과 내부를 구분하는 경계가 있고, 환경에서 자원을 받아 제품·서비스를 공급 |

## 조직화 과정

### 1. 분화와 통합
- 분화의 문제: 조직화는 다양한 구성 요소를 일정한 기준에 따라 전문화
- 통합의 문제: 분화된 작업 노력을 공동 목표를 지향하도록 조정
- 분화와 통합의 정도를 어떻게 유지할 것인가가 조직화 과정의 가장 중요한 의사결정 문제

### 2. 조직화 절차
1. 조직 목표 달성을 위한 전체 업무 파악
2. 업무의 체계적 분할·세분화 (분업·전문화)
3. 업무 성격에 따른 구성원의 집단화(부문화)
4. 목표에 부합하지 않는 행위나 갈등이 생기지 않도록 적절히 조정
5. 조직의 효과성을 유지하기 위한 지속적 평가와 수정

### 3. 조직화의 기본 요소
| 요소 | 내용 |
| --- | --- |
| 전문화 | 경영 목적 달성에 필요한 활동이 세분화되어 개인의 과업이 전문화되고, 이를 통해 작업 공정의 표준화가 가능 |
| 부문화 | 업무를 서로 묶는 수평적 조정의 기본 원칙 |
| 명령 체계 | 조직의 가장 높은 지위에서 낮은 위치까지 연결하는 선 |
| 통제 범위 | 조직 내 계층의 수와 관리자의 수를 결정하므로 중요 |
| 집권화 | 의사결정 권한이 조직 내 어느 한 지점에 집중된 정도 |
| 공식화 | 조직 내 업무가 표준화된 정도 |

- 이해를 위해서는 먼저 과업을 어떻게 할당·구조화할지 정립하고, 분업화된 과업을 조정하며, 전문화와 표준화 개념을 사용하고 적절한 분권화가 요구됨

### 4. 전문화와 직무설계
- 직무 전문화: 전체 과업을 더 작은 요소로 분할하는 것. 세분화를 통해 특정 과업만 담당하는 것이 생산성을 높임
- 지나친 전문화는 인간성 소외로 인한 지루함, 피로, 스트레스, 생산성·품질 저하, 이직·결근율 증가를 초래
- 직무설계: 직무 만족(개인 목표)과 생산성 향상(조직 목표)을 위해 직무의 내용·기능과 직무 간 관계를 규정하는 것. 분업의 원칙에 따라 직무가 배분·설계되고 분업의 정도에 따라 과업 구조가 결정됨

| 단계 | 시기 | 방식 |
| --- | --- | --- |
| 전통적 직무설계 | 1800~1940년대 | 인간을 직무에 적응. 대기업화와 전문화된 기술, 과학적 관리에 따른 직무 전문화 |
| 근대적 직무설계 | 1940년대~현재 | 지나친 전문화에 대응한 직무 순환, 직무 확대 |
| 현대적 직무설계 | 1960년대~현재 | 직무를 인간에 적응. 직무 충실화, 직무 특성 모형 |

- 직무 전문화: 과업을 최대한 세분화해 한정된 범위의 일을 계속 수행하게 함. 단순 직무의 반복으로 능률과 생산성을 높이고 미숙련공 고용으로 훈련비·노무비를 줄이려는 과학적 관리법의 기본 수단
- 직무 순환: 직무 내용은 그대로 두고 여러 직무를 번갈아 수행해 지루함과 단조로움을 극복
- 직무 확대: 과업의 수를 늘려 직무를 수평적으로 확대해 흥미와 다양성을 높임
- 직무 충실화: 내재적 보상에 초점. 허즈버그 2요인이론의 동기요인을 바탕으로 자율성과 책임을 부여하고 성장·의미 있는 작업 경험의 기회를 제공

### 5. 부문화
- 직무 전문화로 나뉜 직무들을 일정한 논리적 배열에 따라 집단화하는 과정
- 조직 규모가 커져 서로 유사하거나 관련 있는 업무·활동을 효과적으로 관리하기 위해 묶음
- 기준은 기능, 제품, 지리, 공정, 고객

| 기준 | 적합한 경우 |
| --- | --- |
| 기능 | 비슷한 전문가를 함께 일하게 해 효율성을 높임 |
| 제품 | 제품과 관련된 모든 활동이 한 경영자의 책임 아래 있어 성과의 책임 소재가 분명 |
| 지리 | 고객이 넓은 지역에 흩어져 있고 위치에 따라 공통의 요구를 가질 때 |
| 공정 | 각 공정에서 서로 다른 기술이 요구될 때 |
| 고객 | 부서의 고객이 공통의 문제와 요구를 가져 해당 분야 전문가가 가장 효과적으로 해결할 수 있을 때 |

- 기능별 부문화: 가장 보편적이며 생산부·판매부·관리부처럼 유사한 작업 활동을 중심으로 집단화. 부서 관리자가 구성원을 효과적으로 관리하고 부서 내 조정이 용이한 반면, 규모가 커지면 의사결정이 지연되고 관료화되며 구성원이 조직 전체에 대한 통찰을 잃고 부서 간 갈등이 생기기 쉬움
- 제품별 부문화: 제품이나 제품군을 중심으로 묶어 생산·판매·연구개발 등 여러 기능을 한 부서에 두는 구조. 독립채산제로 운영되어 부문 간 경쟁과 책임 경영으로 성과를 높이나, 자기 제품에만 관심을 집중해 전체 효율이 떨어지고 기능별 영역이 중복되어 관리비용이 증가

### 6. 조정 활동
- 직무 전문화와 부문화가 이루어진 뒤 각 부문의 다양한 활동을 체계적으로 연계시키는 과정
- 하위 부문이 조직 전체의 유효성보다 능률의 원칙을 따르기 때문에 필요. 예를 들어 생산부서는 최소 원가를, 판매부서는 품질·가격·재고·물류·유통 체계의 혁신을 추구해 갈등이 생김
- 필요성: 업무 간 상호 의존성, 부문·집단 간 이질화 현상

| 조정 방법 | 내용 |
| --- | --- |
| 계층 구조 이용 | 규모가 작고 단순할 때 효과적이나, 규모가 커지고 구조가 복합해지면 어려움 |
| 규칙과 절차 이용 | 표준화된 규칙으로 조정 |
| 수직적 정보 체계 이용 | 상하 간 정보 흐름을 원활히 함. 경영정보시스템, 전자결재, 지식정보시스템 등 |
| 수평적 관계 향상 | 동일한 문제를 처리할 사람들 간 직접 접촉을 권장. 여러 부서 구성원을 포함하는 위원회나 태스크포스 |

## 조직화의 원칙

### 1. 수직적 조정의 원칙
- 권한 계층을 활용해 분화·전문화된 조직 요소를 통합하는 과정
- 계층 연결의 원칙, 명령 일원화의 원칙, 권한·책임·보고 의무의 삼면 등가 원칙, 명령의 연쇄, 관리 영역(감독 범위), 권한 위양, 집권화와 분권화

### 2. 명령의 연쇄
- 부하는 직무 라인에 따라 한 사람의 상사에게서만 명령을 받고 명확한 보고 체계를 가져야 한다는 원칙
- 명령 체계는 권한과 명령의 통일성을 함께 생각해야 함
  - 권한: 관리 직위가 가진 고유의 권리로 명령을 내리고 복종을 기대할 수 있게 함
  - 명령의 통일성: 권한 체계가 끊어지지 않게 하며, 한 종업원에게 오직 한 명의 직속 상관이 있어야 함
- 다수의 상사와 부하 간에 명령·보고 관계가 이루어지면 책임의 일원화가 없고 조직이 혼란과 갈등에 빠지기 쉬움

### 3. 관리 영역(감독 범위)
- 통제 범위는 조직 내 계층의 수와 관리자 수를 결정하므로 중요하며, 통제 범위가 넓을수록 조직이 더 효율적
- 관리 범위: 한 관리자가 가장 효과적으로 관리할 수 있는 종업원의 수
- 범위가 좁으면 관리 계층이 늘어 비용이 많아지고, 수직적 의사소통이 복잡해지며, 지나친 간섭으로 자율성을 저해. 반면 5~6명 정도로 좁히면 밀접한 통제가 가능
- 환경 불확실성의 증가로 의사결정 속도 향상, 유연성 증가, 고객 밀착, 권한 위임을 위해 넓은 통제 범위가 강조됨

| 조직구조 | 관리 영역 | 경영의 계층 수 |
| --- | --- | --- |
| 고층 조직구조 | 좁음 | 많음 |
| 평면 조직구조 | 넓음 | 적음 |

### 4. 권한 위양과 삼면 등가 원칙
- 권한을 가진 관리자가 하위자에게 직무 수행에 관한 일정한 권한을 위임하는 것. 과업을 부하에게 할당하고 위탁하는 과정
- 삼면 등가의 원칙
  - 책임: 무엇을 수행해야 하는지에 대한 수행 책임의 부여
  - 권한: 할당받은 과업을 수행할 수 있도록 필요한 조치를 취할 권한의 부여
  - 보고 의무: 개인적 책임감뿐 아니라 상위자에 대해서도 업무 수행 결과에 대한 책임을 짐

### 5. 집권화와 분권화
| 구분 | 내용 |
| --- | --- |
| 집권화 | 의사결정 권한이 조직 내 어느 한 지점에 집중된 정도. 최고경영진이 낮은 직위 관리자의 참여 없이 주요 의사결정을 내릴 수 있음 |
| 분권화 | 의사결정 권한의 일부를 하위층에 위양해 의사결정 지연이나 책임 회피 문제를 해결. 많은 수가 의사결정에 참여하고 의사결정자와의 거리감이 줄며 상황 변화에 신속히 대처 |
